# Отслеживание продажи

Эндпоинты трекинга sale-событий поддерживают два режима:

- **server-side** — вызывается с бэкенда, использует секретный API-ключ `rr_*`
- **client-side** — вызывается с фронтенда, использует publishable key `rr_pk_*`

## Серверный вызов [#server-side-call]

- Method: `POST`
- URL: `https://api.revroute.ru/track/sale`
- Auth: `Authorization: Bearer rr_*` (ключ из `/<workspace>/settings/tokens`)

```bash
curl -X POST "https://api.revroute.ru/track/sale" \
  -H "Authorization: Bearer rr_xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "customerExternalId": "cus_oFUYbZYqHFR0knk0MjsMC6b0",
    "amount": 99000,
    "paymentProcessor": "custom",
    "eventName": "Invoice paid",
    "invoiceId": "INV_1234567890",
    "currency": "rub"
  }'
```

## Клиентский вызов [#client-side-call]

- Method: `POST`
- URL: `https://api.revroute.ru/track/sale/client`
- Auth: `Authorization: Bearer rr_pk_*` (ключ из `/<workspace>/settings/analytics?step=connect`)

```bash
curl -X POST "https://api.revroute.ru/track/sale/client" \
  -H "Authorization: Bearer rr_pk_xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "customerExternalId": "cus_oFUYbZYqHFR0knk0MjsMC6b0",
    "amount": 99000,
    "paymentProcessor": "custom",
    "eventName": "Invoice paid",
    "invoiceId": "INV_1234567890",
    "currency": "rub"
  }'
```

## Поле `paymentProcessor` [#paymentprocessor-field]

Опциональное поле для пометки источника платежа: `stripe`, `shopify`, `polar`, `paddle`,
`revenuecat` или `custom` — самостоятельная интеграция или другой провайдер (по умолчанию).
Значение вне этого списка записывается как `custom`.

Поле справочное — оно не влияет на атрибуцию или начисление комиссии, но помогает фильтровать события в аналитике по источнику платежа.

## Когда вызывать эндпоинт [#when-to-call-the-endpoint]

Вызывайте `track/sale` **только после успешной оплаты** (например, в обработчике вебхука вашей платёжной системы об успешной оплате). Передача события до подтверждения платежа приведёт к ложным комиссиям, которые потом придётся отзывать.
