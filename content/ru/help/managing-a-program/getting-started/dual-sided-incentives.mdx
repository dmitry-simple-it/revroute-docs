Некоторые примеры:

- Скидка 25% на первые 12 месяцев
- Пожизненная скидка 30%
- Разовая скидка 5000 ₽

Это может стимулировать мощный рост через «сарафанное радио», поскольку партнеры с большей вероятностью будут делиться своей ссылкой, если она дает их аудитории дополнительные скидки, а с другой стороны, их пользователи с большей вероятностью будут переходить по ссылкам, если получат специальное предложение.

В этой статье мы узнаем, как настроить двусторонние стимулы с Revroute Partners.

<Note>
  Для двусторонних стимулов вам нужна биллинговая система на вашей стороне,
  которая поддерживает купоны или промокоды. Revroute хранит идентификатор
  купона, созданного/зарегистрированного в вашей биллинговой системе, и
  передаёт его в ваш процесс оформления заказа — ваше приложение отвечает за
  применение этого купона при оплате.
</Note>

## Вариант 1: Скидки на основе ссылок (рекомендуется)

Этот вариант привязывает скидку к самой реферальной ссылке партнера. Клиенту не нужно вводить код — ваш чекаут автоматически применяет нужный купон в зависимости от того, какой партнер его привёл.

<Note>
Скидки на основе ссылок обеспечивают **лучшую точность атрибуции**, так как вы
получаете информацию о геолокации клиента, устройстве, данных реферера и
UTM-параметрах.

Компромисс заключается в том, что для настройки требуется некоторая работа разработчиков.

</Note>

<Steps>
<Step title="Создайте скидку в Revroute">
Сначала перейдите к группе партнеров, для которой вы хотите создать скидку. На вкладке Discount вы сможете создать скидку для группы

![Страница скидок группы](https://s3.revroute.ru/dub-public/assets/cms/group-discounts-empty.png)

Если у вас уже настроена скидка для группы по умолчанию, вы можете просто продублировать её. Если нет, нажмите Create, чтобы создать первую скидку группы:

![Вкладка скидок программы](/images/dub-partners/new-discount-reward.png)

**Новый купон**

Если в вашей биллинговой системе ещё нет купона, вы можете использовать опцию New coupon, чтобы создать новый купон на основе типа скидки (процент или фиксированная сумма), суммы и длительности, установленных в Revroute.

**Использовать ID существующего купона**

Если у вас уже есть купон в биллинговой системе, вы можете ввести его ID (обычно 8-символьный буквенно-цифровой код) в поле Use existing coupon ID.

<Warning>
Большинство биллинговых систем не поддерживают обновление купонов после
создания, поэтому если вы хотите изменить параметры скидки — придётся удалить
её в Revroute и создать новую.

Примечание: Удаление скидки в Revroute не удаляет соответствующий купон в
вашей биллинговой системе.

</Warning>

</Step>

<Step title="Добавьте логику купона в процесс оформления заказа">
Ключ к реализации скидок на основе ссылок — проверка права клиента на скидку через Customers API от Revroute, а затем автоматическое применение соответствующего купона к сессии оформления заказа.

Вот как работает процесс:

1. Когда пользователь нажимает на реферальную ссылку партнера, Revroute отслеживает его как потенциального клиента
2. Во время оформления заказа вы запрашиваете Customers API от Revroute, используя ID пользователя
3. Если клиент имеет право на скидку, вы применяете купон к сессии оформления заказа в вашей биллинговой системе
4. Если нет, вы разрешаете ручной ввод промокодов

Пример ниже иллюстрирует логику с обобщённым клиентом биллинговой системы. Замените `billing.checkout.create(...)` на эквивалентный вызов в вашей биллинговой системе.

<CodeGroup>

```ts TypeScript expandable
import { dub } from "@/lib/dub.ts";
import { billing } from "@/lib/billing.ts"; // клиент вашей биллинговой системы

// Get customer discount eligibility from Revroute
const customers = await dub.customers.list({
  externalId: userId, // their user ID within your app
  includeExpandedFields: true,
});

const customerDiscount = customers.length > 0 ? customers[0].discount : null;

// Create checkout session with conditional discount
const session = await billing.checkout.create({
  successUrl: "https://app.domain.com/upgraded",
  cancelUrl: "https://app.domain.com/pricing",
  lineItems: [
    {
      priceId: "price_xxx",
      quantity: 1,
    },
  ],
  mode: "subscription", // or "payment" for one-time purchases
  ...(customerDiscount
    ? {
        // Apply discount automatically if customer is eligible
        couponId:
          process.env.NODE_ENV !== "production" &&
          customerDiscount.couponTestId
            ? customerDiscount.couponTestId
            : customerDiscount.couponId,
      }
    : {
        // Allow manual promo code entry if no automatic discount
        allowPromotionCodes: true,
      }),
  customerEmail: userEmail,
  metadata: {
    userId,
    ...(customerDiscount && { dubDiscountId: customerDiscount.id }),
  },
});
```

```python Python expandable
from dub import Revroute
from billing import client as billing  # клиент вашей биллинговой системы
import os

dub_client = Revroute(token=os.environ.get("DUB_API_KEY"))

user_id = "user_123"  # the user's ID in your app

# Get customer discount eligibility from Revroute
customers = dub_client.customers.list(
    email=None,
    external_id=user_id,
    include_expanded_fields=True
)

# Prepare checkout session parameters
session_params = {
    "success_url": "https://app.domain.com/upgraded",
    "cancel_url": "https://app.domain.com/pricing",
    "line_items": [{"price": "price_xxx", "quantity": 1}],
    "mode": "subscription",  # or "payment" for one-time purchases
    "customer_email": user_email,
    "metadata": {
        "userId": user_id,
    },
}

# Apply discount if customer is eligible
if customers and hasattr(customers[0], "discount") and customers[0].discount and customers[0].discount.coupon_id:
    coupon_id = customers[0].discount.coupon_test_id if (
        os.environ.get("NODE_ENV") != "production"
    ) and hasattr(customers[0].discount, "coupon_test_id") else customers[0].discount.coupon_id

    session_params["coupon_id"] = coupon_id
    session_params["metadata"]["dubDiscountId"] = customers[0].discount.id
else:
    session_params["allow_promotion_codes"] = True

# Create the checkout session
session = billing.checkout.create(**session_params)
```

</CodeGroup>

После настройки подходящие клиенты автоматически увидят применённый промокод при оформлении заказа.

</Step>

</Steps>

## Вариант 2: Использование промокодов (без кода)

Если вы предпочитаете решение без кода, вы можете настроить скидки на основе промокодов для ваших партнеров.

<Note>
Скидки на основе промокодов гораздо проще настроить (код не требуется).

Однако вы жертвуете точностью атрибуции, так как у вас не будет данных
о геолокации клиента, устройстве, реферере и UTM-параметрах. Revroute
попытается определить местоположение клиента на основе его платёжного адреса
в вашей биллинговой системе, но это может быть неточным.

</Note>

### Автоматическое создание кодов скидок

Когда включено, коды скидок будут автоматически созданы для всех существующих партнеров в этой группе и будущих партнеров при вступлении в эту группу.

![Автоматическое создание кодов скидок](/images/dub-partners/auto-provision-code.png)

</Step>

<Step title="Создайте код партнера">
Откройте профиль партнера, для которого вы хотите создать код скидки, затем нажмите Create Code в разделе «Discount codes».

![Страница ссылок партнера](https://s3.revroute.ru/dub-public/assets/cms/partner-create-code.png)

Здесь вы можете выбрать, с какой реферальной ссылкой связать код. Затем вы можете создать код скидки.

![Страница ссылок партнера](https://s3.revroute.ru/dub-public/assets/cms/new-discount-code.png)

<Warning>
  Коды скидок нельзя редактировать после создания, поэтому убедитесь, что все
  данные верны перед созданием кода
</Warning>

После создания кода его значение появится в разделе Discount Code, и он будет готов к использованию. В панели партнера они также увидят связанный код скидки в своих партнерских ссылках.

![Страница ссылок партнера с кодом скидки](https://s3.revroute.ru/dub-public/assets/cms/partner-code-created.png)

</Step>
</Steps>

Для этого вам нужно только установить [скрипт Revroute Analytics](/docs/sdks/client-side/introduction) с включенным отслеживанием кликов на стороне клиента — тогда, когда кто-то перейдет на ваш сайт по действительной реферальной ссылке, скрипт автоматически получит данные о партнере и скидке.
