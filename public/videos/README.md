# Видео и скриншоты лендинга (DS v2)

## Интро/промо-видео
Уже подключено на **/prm** (секция «Демо»; кнопка «Посмотреть демо» в герое скроллит к нему).
Файлы (web-ready, self-host — без YouTube):

```
public/videos/revroute-promo.webm        ← основной (VP9/Opus, со звуком)
public/videos/revroute-promo.mp4         ← фолбэк (H.264 +faststart, Safari/iOS)
public/videos/revroute-promo-poster.jpg  ← постер (реальный кабинет)
```

Режим — click-to-play со звуком (`<video controls>`), webm-источник первым. Чтобы обновить ролик — замените эти файлы (имена те же). Для hero-фона с автоплеем есть muted-версии в исходном проекте (`partners-promo/dist-web/`), при необходимости докину.

## Скриншоты интерфейса
Русскоязычные экраны кабинета лежат в:

```
public/images/screenshots/ru/<имя>.png
```

| Файл | Что | Где используется |
|------|-----|------------------|
| `overview.png` | Обзор программы (вендор) | /prm hero, /solutions/saas (сегменты) |
| `analytics.png` | Аналитика: клики/лиды/продажи | /prm и /saas — атрибуция |
| `payouts.png` | Выплаты партнёрам | /prm — блок расчётов |
| `rewards.png` | Редактор вознаграждений | /prm и /saas — стимулы |
| `branding.png` | AI-лендинги / брендинг | /prm — AI-лендинги |
| `marketplace.png` | Каталог программ | (резерв — для «Партнёрской сети») |
| `partner-overview.png` | Кабинет партнёра | не используется (есть непереведённый ключ в UI) |

Ссылаться: `/images/screenshots/ru/<имя>.png`. Все 1920×1080, с честной пометкой «Данные демо-программы».

**Без RU-версии пока:** `events.png` (антифрод) и `ltv-customer.png` (когорты/LTV) — остаются англоязычными до новых скриншотов.
