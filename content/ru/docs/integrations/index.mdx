## Создание собственных интеграций

Вы можете создавать собственные интеграции с инфраструктурой ссылок Revroute, используя наш [API](/docs/api-reference/introduction).

1. Ознакомьтесь с [введением в API](/docs/api-reference/introduction) и документацией по [отслеживанию конверсий продаж](/docs/api-reference/endpoint/track-sale).
2. Узнайте, как [интегрировать Revroute в ваше приложение](/docs/integrations/quickstart).
3. [Свяжитесь с нами](/contact/support), чтобы разместить вашу интеграцию в маркетплейсе интеграций.

## Вебхуки интеграций

Revroute также поддерживает вебхуки для интеграций. Подробнее о них можно узнать в документации по [вебхукам](/docs/webhooks).

Вот список вебхуков, которые поддерживает Revroute:

- [`link.created`](/docs/webhooks/events#linkcreated) — при создании новой ссылки
- [`link.updated`](/docs/webhooks/events#linkupdated) — при обновлении ссылки
- [`link.deleted`](/docs/webhooks/events#linkdeleted) — при удалении ссылки
- [`link.clicked`](/docs/webhooks/events#linkclicked) — при клике по ссылке
- [`lead.created`](/docs/webhooks/events#leadcreated) — при создании нового лида
- [`sale.created`](/docs/webhooks/events#salecreated) — при создании новой продажи
- [`partner.enrolled`](/docs/webhooks/events#partnerenrolled) — при регистрации нового партнёра в вашей программе
