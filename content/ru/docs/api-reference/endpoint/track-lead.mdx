# Отслеживание лида

Эндпоинты трекинга lead‑событий поддерживают два режима:

- **server-side** — вызывается с бэкенда, использует секретный API‑ключ `rr_*`
- **client-side** — вызывается с фронтенда, использует publishable key `rr_pk_*`

## Серверный вызов

- Method: `POST`
- URL: `https://api.revroute.ru/track/lead`
- Auth: `Authorization: Bearer rr_*` (ключ из `/<workspace>/settings/tokens`)

```bash
curl -X POST "https://api.revroute.ru/track/lead" \
  -H "Authorization: Bearer rr_xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "clickId": "rLnWe1uz9t282v7g",
    "eventName": "Sign up",
    "customerExternalId": "cus_oFUYbZYqHFR0knk0MjsMC6b0",
    "customerName": "John Doe",
    "customerEmail": "john.doe@example.com",
    "customerAvatar": "https://example.com/avatar.png"
  }'
```

## Клиентский вызов

- Method: `POST`
- URL: `https://api.revroute.ru/track/lead/client`
- Auth: `Authorization: Bearer rr_pk_*` (ключ из `/<workspace>/settings/analytics?step=connect`)

```bash
curl -X POST "https://api.revroute.ru/track/lead/client" \
  -H "Authorization: Bearer rr_pk_xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "clickId": "rLnWe1uz9t282v7g",
    "eventName": "Sign up",
    "customerExternalId": "cus_oFUYbZYqHFR0knk0MjsMC6b0",
    "customerName": "John Doe",
    "customerEmail": "john.doe@example.com",
    "customerAvatar": "https://example.com/avatar.png"
  }'
```
