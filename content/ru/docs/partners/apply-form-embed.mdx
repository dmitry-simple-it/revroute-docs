# Форма заявки в программу на вашем сайте

Форму вступления в партнёрскую программу можно показать прямо на странице вашего сайта: будущий партнёр заполняет её, не уходя к нам. Форма открывается только на ваших сайтах — на чужом браузер её не покажет.

Работает на любом тарифе. Нужна опубликованная форма заявки: **Брендинг → Форма заявки → Опубликовать**.

## Разрешите свой сайт [#allow-your-website]

Сайт, который указан в настройках программы, уже разрешён. Если форма будет на другом домене или поддомене, добавьте его.

### 1. «Аналитика» [#1-analytics]

Откройте **Настройки → Аналитика**.

### 2. «Добавить хост» [#2-add-host]

В блоке **«Разрешённые хосты»** нажмите **«Добавить хост»**.

![Настройки → Аналитика: 1 — пункт «Аналитика», 2 — кнопка «Добавить хост»](/images/ru/program/apply-form-embed/apply-form-embed-1-allowed-hosts.png)

### 3. Адрес сайта [#3-website-address]

Введите домен без `https://`, например `example.com`. Вариант с `www` разрешается вместе с ним. Чтобы разрешить все поддомены, введите `*.example.com`.

### 4. Сохраните [#4-save]

Нажмите **«Добавить»**. Изменение действует сразу.

![Окно «Добавить хостнейм»: 3 — домен сайта, 4 — кнопка «Добавить»](/images/ru/program/apply-form-embed/apply-form-embed-2-add-host.png)

<Warning>
  Этот же список ограничивает клиентский скрипт RevRoute: с непустым списком переходы засчитываются только на перечисленных сайтах. Добавьте все сайты, где установлен скрипт.
</Warning>

## Скопируйте ссылку на форму [#copy-the-form-link]

### 5. «Обзор» [#5-overview]

Откройте **Партнёрская программа → Обзор**.

### 6. «Форма заявки» [#6-application-form]

В блоке **«Ссылки программы»** наведите курсор на строку **«Форма заявки»** и нажмите кнопку копирования справа. Ссылка выглядит так: `https://partners.revroute.ru/<программа>/apply`.

![Обзор программы: 5 — пункт «Обзор», 6 — строка «Форма заявки»](/images/ru/program/apply-form-embed/apply-form-embed-3-form-link.png)

Форма для отдельной группы партнёров открывается по адресу `https://partners.revroute.ru/<программа>/<группа>/apply`.

## Вставьте код на страницу [#add-the-code-to-your-page]

Вставьте на страницу сайта блок с формой и короткий скрипт. Скрипт подгоняет высоту блока под форму, чтобы у неё не было своей полосы прокрутки. В `src` — ссылка из шага 6.

```html
<iframe
  id="revroute-apply"
  src="https://partners.revroute.ru/<программа>/apply"
  style="width: 100%; height: 900px; border: 0;"
  title="Заявка в партнёрскую программу"
></iframe>
<script>
  window.addEventListener("message", function (event) {
    if (event.origin !== "https://partners.revroute.ru") return;
    if (event.data && event.data.event === "PAGE_HEIGHT") {
      document.getElementById("revroute-apply").style.height =
        event.data.data.height + "px";
    }
  });
</script>
```

Страница вашего сайта должна открываться по `https`.

## Что видит партнёр [#what-the-partner-sees]

Форма открывается внутри вашей страницы, без шапки RevRoute: награды программы, поля заявки и кнопка **«Продолжить»**.

![Форма заявки на странице сайта вендора](/images/ru/program/apply-form-embed/apply-form-embed-4-result.png)

После отправки там же появляется второй шаг — **«Завершите подачу заявки»**. Кнопки **«Создать аккаунт RevRoute Partners»** и **«Войти в RevRoute Partners»** открывают кабинет партнёра в новой вкладке. Заявка уходит к вам, когда партнёр создаст аккаунт на тот же email; она появится в разделе **Партнёры → Заявки**.

## Если форма не показывается [#if-the-form-doesnt-show]

На месте формы серый блок с грустным значком — браузер не нашёл ваш сайт в списке разрешённых.

1. Проверьте, что в **«Разрешённых хостах»** записан именно этот домен или поддомен (`app.example.com` и `example.com` — разные хосты).
2. Проверьте, что страница открыта по `https`.
3. Проверьте, что форма заявки опубликована: ссылка из шага 6 должна открываться в отдельной вкладке.
