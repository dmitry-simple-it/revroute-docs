# How to set a not found URL for your custom domains

<Tip>
  This feature is only available on [Pro plans and
  above](https://revroute.ru/pricing).
</Tip>

By default, when a user visits a short link that doesn't exist on RevRoute, they will see a standard "not found" placeholder page.

If you are [using a custom domain on RevRoute](/help/managing-your-links/custom-domains/how-to-add-custom-domain), you can set a custom URL to redirect users to when a short link under your domain is not found.

To set a custom not found URL for your domains, follow the steps below:

1. Go to [**Settings → Domains**](https://app.revroute.ru/settings/domains).
2. Click the `⋮` button next to the domain and, under the **Domain settings** section, select **Edit domain**.

![Domain menu: the domain settings section with the edit domain option](/images/ru/links/domain-row-menu.jpg)

3. In the **Update domain** modal, enable the **Not found URL** toggle and enter the custom URL to redirect users to when a short link under your domain is not found.
4. Click the **Save changes** button.

![The update domain modal with the not found URL toggle and the save changes button](/images/ru/links/domain-update-modal.jpg)

The same **Not found URL** toggle is also available in the **Add domain** modal, so you can enable it right when connecting a domain.
