## Установка

<Steps>

<Step title="Установите плагин @dub/better-auth">

Для начала установите [плагин `@dub/better-auth`](https://www.npmjs.com/package/@dub/better-auth) любым пакетным менеджером:

<CodeGroup>

```bash npm
npm install @dub/better-auth
```

```bash yarn
yarn add @dub/better-auth
```

```bash pnpm
pnpm add @dub/better-auth
```

```bash bun
bun add @dub/better-auth
```

</CodeGroup>

</Step>

<Step title="Подключите плагин">

Затем добавьте плагин в конфигурационный файл better-auth:

```ts auth.ts
import { dubAnalytics } from "@dub/better-auth";
import { betterAuth } from "better-auth";
import { Revroute } from "dub";

const dub = new Revroute();

export const auth = betterAuth({
  plugins: [
    dubAnalytics({
      dubClient: dub,
    }),
  ],
});
```

</Step>

</Steps>
