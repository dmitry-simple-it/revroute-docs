title: "Обзор встраиваемых компонентов"
description: "Встройте полнофункциональный реферальный дашборд RevRoute в собственное приложение одним React-компонентом."
---

Встраиваемые компоненты позволяют добавить реферальные и партнёрские функции в продукт, не строя их с нуля. Пользователи логинятся в **ваше** приложение как обычно; на сервере вы выпускаете short-lived embed-токен; React-компонент рендерит соответствующий UI RevRoute прямо на вашей странице — оформленный под ваш бренд.

## Что можно встроить

| Компонент | Что показывает |
| --- | --- |
| Реферальный дашборд | Заработок партнёра, его ссылка, статистика кликов/лидов/продаж, история выплат. Используется внутри SaaS-кабинетов для вкладки "Приведи друга". |

Больше компонентов (аналитика, каталог партнёров, инбокс баунти) — в roadmap. Эта страница — entry-point; единственный сегодня доступный embed описан в [Реферальном дашборде](/docs/embedded-components/referral-dashboard).

## Архитектура

<Steps>
  <Step title="Пользователь логинится в ваше приложение">
    Ваша существующая авторизация — RevRoute здесь невидим.
  </Step>
  <Step title="Бэкенд выпускает embed-токен">
    Вызывает `POST https://api.revroute.ru/tokens/embed/referrals` с workspace-API-ключом и идентификатором партнёра. В ответ — short-lived JWT (`dub_embed_...`), привязанный к одному этому партнёру.
  </Step>
  <Step title="Фронтенд монтирует компонент">
    Передайте токен в `<DubEmbed />` из `@dub/embed-react`. Компонент рендерит `<iframe>`, хостящийся у RevRoute, и автоматически логинит пользователя.
  </Step>
  <Step title="Компонент обновляется в реальном времени">
    Счётчики кликов, лидов и продаж обновляются по мере новых событий — ваш фронтенд не должен поллить.
  </Step>
</Steps>

## Когда использовать embed, а когда API

| Хочу… | Использовать |
| --- | --- |
| Показать партнёру его собственный дашборд внутри моего приложения | **Embed-компоненты** |
| Построить полностью кастомный UI поверх своей модели данных | [REST API](/docs/api-reference/introduction) |
| Отправить пользователя в хостящийся RevRoute партнёрский портал | Обычная ссылка на `partners.revroute.ru` |

Embed — самый быстрый путь: ноль работы над UI, темизация через props, автоматические обновления.

## Модель безопасности

- Embed-токены **per-partner** и **short-lived** (~1 час). Они не могут читать данные других партнёров.
- Токены подписаны RevRoute и проверяются внутри iframe — ваш фронтенд никогда не получает долгоживущий секрет.
- iframe общается с родителем только через узкий `postMessage`-протокол (resize-события, click-телеметрия). Никакого cross-origin доступа к данным.
- Эндпоинт выдачи токена требует ваш **server-side** API-ключ — никогда не выставляйте его в браузер. Браузер видит только embed-токен.
