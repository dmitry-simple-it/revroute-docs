# Ручная установка

Вы можете добавить клиентский скрипт RevRoute на сайт так же, как вы добавляете скрипт Google Analytics или любой другой JavaScript‑код — вставьте его в секцию `<head>` вашего HTML‑файла.

<Tip>
  Готовый скрипт с настройками вашего кабинета (домен программы, нужный вариант скрипта, ключ) — в разделе **Настройки → Аналитика**. Его можно скопировать целиком.
</Tip>

```html
<script
  defer
  src="https://app.revroute.ru/analytics/script.js"
  data-api-host="https://api.revroute.ru"
  data-domains='{"refer": "go.example.com"}'
></script>
```

- `data-api-host` — адрес, куда скрипт отправляет клики. **Обязателен**: без него скрипт отправляет запросы на ваш собственный сайт, и переходы партнёров не засчитываются.
- `data-domains` → `refer` — домен партнёрских ссылок вашей программы. Нужен, чтобы засчитывались переходы по ссылкам вида `example.com?via=имя-партнёра`. Сменили домен программы — обновите и это значение.

## Кросс‑доменный трекинг [#cross-domain-tracking]

Если вам нужно склеивать атрибуцию между разными доменами (например, лендинг → приложение), подключите вариант `outbound-domains` и настройте список доменов, на которые скрипт будет автоматически добавлять идентификатор.

```html
<script
  defer
  src="https://app.revroute.ru/analytics/script.outbound-domains.js"
  data-api-host="https://api.revroute.ru"
  data-domains='{"refer": "go.example.com", "outbound": ["app.example.com"]}'
></script>
```
