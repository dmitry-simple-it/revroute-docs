# Как настроить URL для страницы «не найдено» для ваших пользовательских доменов

<Tip>
  Эта функция доступна только на [тарифных планах Pro и
  выше](https://revroute.ru/pricing).
</Tip>

По умолчанию, когда пользователь переходит по короткой ссылке, которой не существует в RevRoute, он видит стандартную страницу-заглушку «не найдено».

Если вы [используете пользовательский домен в RevRoute](/help/managing-your-links/custom-domains/how-to-add-custom-domain), вы можете задать свой URL, на который будут перенаправляться пользователи, когда короткая ссылка на вашем домене не найдена.

Чтобы настроить URL для страницы «не найдено», выполните следующие шаги:

1. Перейдите в [**Настройки → Домены**](https://app.revroute.ru/settings/domains).
2. Нажмите кнопку `⋮` рядом с нужным доменом и в разделе **Настройки домена** выберите **Редактировать домен**.

![Меню домена: раздел «Настройки домена» с пунктом «Редактировать домен»](/images/ru/links/domain-row-menu.jpg)

3. В открывшейся модалке **Обновить домен** включите тумблер **URL «Не найдено»** и введите URL, на который перенаправлять пользователей, когда короткая ссылка на вашем домене не найдена.
4. Нажмите кнопку **Сохранить изменения**.

![Модалка «Обновить домен» с тумблером «URL «Не найдено»» и кнопкой «Сохранить изменения»](/images/ru/links/domain-update-modal.jpg)

Тот же тумблер **URL «Не найдено»** есть и в модалке **Добавить домен** — его можно включить сразу при подключении домена.
