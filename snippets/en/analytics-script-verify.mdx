<Note>

You can verify the installation in two ways:

1. Open the browser console and type `_revRouteAnalytics` — if the script is
   installed, the object shows up in the console.
2. Add the `?rr_id=test` query parameter to your site URL and check that the
   `rr_id` cookie is set in your browser.

If neither works, make sure that:

- the script tag sits in the `<head>` section of the page;
- any CDN cache in front of your site has been purged.

</Note>
