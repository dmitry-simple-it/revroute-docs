# Как использовать таргетинг по устройствам в RevRoute?

<Tip>
  Эта функция доступна только на [тарифных планах Pro и
  выше](https://revroute.ru/pricing).
</Tip>

Таргетинг по устройствам — это мощная функция, которая позволяет персонализировать целевой URL ваших ссылок в зависимости от типа устройства пользователя.

Например, вы можете указать отдельный целевой URL для устройств iOS в секции «iOS Таргетинг» и другой URL для устройств Android — в секции «Android Таргетинг» [конструктора ссылок](/help/managing-your-links/additional-guides/link-builder).

Чтобы использовать эту функцию, нажмите кнопку **Таргетинг** в конструкторе ссылок. Откроется модальное окно «Таргетинг» с секциями «Гео-таргетинг», «iOS Таргетинг» и «Android Таргетинг». Заполните нужные поля и нажмите кнопку **Добавить таргетинг**.

Вы также можете быстро открыть модальное окно «Таргетинг» с помощью сочетания клавиш `G` в конструкторе ссылок.

![Использование таргетинга по устройствам для персонализации ссылки](/images/ru/links/targeting-modal-filled.jpg)

Это особенно полезно, если вы хотите направить пользователей iOS в App Store для скачивания вашего iOS-приложения, а пользователей Android — в Google Play Store для скачивания вашего Android-приложения.

В обоих случаях основной **URL назначения** будет использоваться как резервный URL, который применяется, если тип устройства пользователя не соответствует правилам таргетинга.
