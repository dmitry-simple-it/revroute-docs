В Revroute вы можете создавать диплинки, позволяющие перенаправлять пользователей на определённую страницу вашего мобильного приложения.

![Deep links on Revroute](https://s3.revroute.ru/dub-public/assets/cms/deep-links.jpg)

Например, вы создаёте рекламную кампанию для привлечения трафика на страницу конкретного продукта в вашем мобильном приложении.

Следуя приведённому ниже руководству быстрого старта, вы сможете настроить все ваши короткие ссылки с функциональностью диплинков.

## Шаг 1: Настройте домены диплинков в Revroute

Прежде чем создавать диплинки, необходимо настроить домены диплинков в вашем рабочем пространстве Revroute. Для этого нужно добавить пользовательский домен, который будет использоваться для диплинков, и настроить конфигурационные файлы диплинков.

### Добавление пользовательского домена

Сначала необходимо добавить пользовательский домен в ваше рабочее пространство Revroute. Перейдите в [настройки доменов рабочего пространства](https://app.revroute.ru/settings/domains) и нажмите **Add Domain**.

Вы можете использовать домен, которым уже владеете, или воспользоваться нашим [предложением бесплатного домена .link](/help/managing-your-links/custom-domains/free-dot-link-domain) для регистрации пользовательского домена, например `yourcompany.link`, и использовать его как домен диплинков.

### Настройка конфигурационных файлов диплинков

После настройки пользовательского домена необходимо загрузить конфигурационные файлы диплинков в Revroute, которые мы будем размещать в директории `/.well-known/` вашего домена.

Для этого перейдите в [настройки доменов рабочего пространства](https://app.revroute.ru/settings/domains) и нажмите кнопку редактирования для вашего пользовательского домена:

![Deep link configuration files](https://s3.revroute.ru/dub-public/assets/cms/update-domain-button.png)

В открывшемся окне домена нажмите **Show advanced settings** — появятся поля настройки конфигурации диплинков.

![Deep link configuration settings](https://s3.revroute.ru/dub-public/assets/cms/domain-modal-advanced-settings.png)

**iOS (apple-app-site-association)**

Для приложений на iOS загрузите [файл Apple App Site Association](https://developer.apple.com/documentation/xcode/supporting-associated-domains#Add-the-associated-domain-file-to-your-website) — он включает диплинки на iOS:

```json apple-app-site-association
{
  "applinks": {
    "apps": [],
    "details": [
      {
        "appID": "<YOUR_APPLICATION_IDENTIFIER_PREFIX>.<YOUR_APPLICATION_BUNDLE_IDENTIFIER>",
        "paths": []
      }
    ]
  }
}
```

<Note>
  После обновления файла AASA приложение может потребоваться переустановить: iOS
  кеширует старую версию файла, из-за чего поведение становится непредсказуемым.
</Note>

**Android (assetlinks.json)**

Для приложений на Android загрузите файл AssetLinks — он включает диплинки на Android:

```json assetlinks.json
[
  {
    "target": {
      "namespace": "android_app",
      "package_name": "YOUR_PACKAGE_NAME",
      "sha256_cert_fingerprints": []
    },
    "relation": ["delegate_permission/common.handle_all_urls"]
  }
]
```

### Проверьте конфигурационные файлы

После загрузки конфигурационных файлов откройте их по прямым адресам и убедитесь, что они отдаются:

**iOS:** `yourdomain.link/.well-known/apple-app-site-association` [(пример)](https://getacme.link/.well-known/apple-app-site-association)

**Android:** `yourdomain.link/.well-known/assetlinks.json` [(пример)](https://getacme.link/.well-known/assetlinks.json)

### Разрешите домен диплинков в приложении

Наконец, домен диплинков нужно внести в список разрешённых в самом приложении — иначе оно не сможет открывать нужный экран напрямую.

**Для приложений на iOS** — [разрешите сайтам ссылаться на ваше приложение](https://developer.apple.com/documentation/xcode/allowing-apps-and-websites-to-link-to-your-content/).

**Для приложений на Android** — [подтвердите ссылки приложения](https://developer.android.com/training/app-links/verify-android-applinks).

## Шаг 2: Создайте диплинки в Revroute

Домены настроены — теперь можно создавать диплинки, которые открывают конкретный экран вашего приложения.

### Укажите целевой URL

Откройте [кабинет Revroute](https://app.revroute.ru) и нажмите **Create Link** в верхней панели.

Введите целевой URL в поле «Destination URL». Протокол `https://` можно не указывать — Revroute приведёт адрес к корректному виду сам.

Это тот адрес, который открывает конкретный экран или материал в приложении. Например, `https://yourapp.com/product/Apple-MacBook` открывает карточку товара `Apple-MacBook`.

![Deep link builder](https://s3.revroute.ru/dub-public/assets/help/link-builder.jpg)

### Задайте слаг короткой ссылки

В поле Short Link можно:

1. Ввести собственный слаг
2. Сгенерировать случайный слаг
3. Сгенерировать слаг с помощью ИИ

Например, слаг `apple-macbook` будет открывать карточку товара `Apple-MacBook`.

<Tip>
  Шаг необязательный: если слаг не указать, Revroute сгенерирует случайный слаг
  из 7 символов.
</Tip>

### Настройте таргетинг по устройствам

[Таргетинг по устройствам](/help/managing-your-links/links/device-targeting) отправляет пользователя в App Store или Google Play, если приложение не установлено.

Разные целевые адреса для разных платформ задаются прямо в конструкторе ссылок: поле **iOS Targeting** — для устройств на iOS, **Android Targeting** — для Android.

![Deep link device targeting configuration](https://s3.revroute.ru/dub-public/assets/help/device-targeting.png)

Осталось нажать **Create link**. Полученная ссылка заменяет Firebase Dynamic Link.

<Note>
  В конструкторе ссылок Revroute есть и другие возможности: UTM-конструктор,
  защита паролем, срок действия, гео-таргетинг. Полный список — в статье
  [«Как создать короткую ссылку»](/help/managing-your-links/links/how-to-create-link).
</Note>

## Шаг 3: Обработка переходов по диплинкам в приложении

Когда пользователь открывает приложение по диплинку, нужно предусмотреть два сценария.

### Сценарий 1: приложение уже установлено

Диплинк открывает приложение напрямую. Обработать переход можно вручную или через мобильный SDK.

**Вариант 1**: обработка через мобильный SDK Revroute (только iOS и React Native).

Начните с руководства по установке для [Swift](/docs/sdks/client-side-mobile/installation-guides/swift) или [React Native](/docs/sdks/client-side-mobile/installation-guides/react-native).

<CodeGroup>

```typescript React Native expandable
import { useState, useEffect, useRef } from "react";
import { Linking } from "react-native";
import AsyncStorage from "@react-native-async-storage/async-storage";
import dub from "@dub/react-native";

export default function App() {
  useEffect(() => {
    dub.init({
      publishableKey: "<DUB_PUBLISHABLE_KEY>",
      domain: "<DUB_DOMAIN>",
      baseUrl: "https://api.revroute.ru",
    });

    // Check if this is first launch
    const isFirstLaunch = await AsyncStorage.getItem("is_first_launch");

    if (isFirstLaunch === null) {
      await handleFirstLaunch();
      await AsyncStorage.setItem("is_first_launch", "false");
    } else {
      // Handle initial deep link url (Android only)
      const url = await Linking.getInitialURL();

      if (url) {
        await handleDeepLink(url);
      }
    }

    const linkingListener = Linking.addEventListener("url", (event) => {
      handleDeepLink(event.url);
    });

    return () => {
      linkingListener.remove();
    };
  }, []);

  const handleFirstLaunch = async (
    deepLinkUrl?: string | null | undefined,
  ): Promise<void> => {
    try {
      const response = await dub.trackOpen(deepLinkUrl);

      const destinationURL = response.link?.url;
      // Navigate to the destination URL
    } catch (error) {
      // Handle error
    }
  };

  // Return your app...
}
```

```swift iOS (SwiftUI) expandable
// ContentView.swift
import SwiftUI
import Revroute

struct ContentView: View {

    @Environment(\.dub) var dub: Revroute

    @AppStorage("is_first_launch") private var isFirstLaunch = true

    var body: some View {
        NavigationStack {
            VStack {
                // Your app content
            }
            .onOpenURL { url in
                trackOpen(deepLink: url)
            }
            .onAppear {
                if isFirstLaunch {
                    trackOpen()
                    isFirstLaunch = false
                }
            }
        }
    }

    private func trackOpen(deepLink: URL? = nil) {
        Task {
            do {
                let response = try await dub.trackOpen(deepLink: deepLink)

                // Obtain the destination URL from the response
                guard let url = response.link?.url else {
                    return
                }

                // Navigate to the destination URL
            } catch let error as DubError {
                print(error.localizedDescription)
            }
        }
    }
}
```

```swift iOS (UIKit) expandable
import UIKit
import Revroute

@main
class AppDelegate: UIResponder, UIApplicationDelegate {

    var window: UIWindow?

    private let dubPublishableKey = "<DUB_PUBLISHABLE_KEY>"
    private let dubDomain = "<DUB_DOMAIN>"

    private var isFirstLaunch: Bool {
        get {
            UserDefaults.standard.object(forKey: "is_first_launch") as? Bool ?? true
        }
        set {
            UserDefaults.standard.set(newValue, forKey: "is_first_launch")
        }
    }

    func application(_ application: UIApplication, didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
        Revroute.setup(publishableKey: dubPublishableKey, domain: dubDomain)

        // Track first launch
        if isFirstLaunch {
            trackOpen()
            isFirstLaunch = false
        }

        // Override point for customization after application launch.
        return true
    }

    func application(_ app: UIApplication, open url: URL, options: [UIApplication.OpenURLOptionsKey : Any] = [:]) -> Bool {
        handleDeepLink(url: url)
        return true
    }

    func handleDeepLink(url: URL) {
        trackOpen(deepLink: url)
    }

    private func trackOpen(deepLink: URL? = nil) {
        // Call the tracking endpoint with the full deep link URL
        Task {
            do {
                let response = try await Revroute.shared.trackOpen(deepLink: deepLink)

                print(response)

                // Navigate to final link via link.url
                guard let destinationUrl = response.link?.url else {
                    return
                }

                // Navigate to the destination URL
            } catch let error as DubError {
                print(error.localizedDescription)
            }
        }
    }
}
```

<Step title="Отправьте событие открытия">

Получив и разобрав диплинк, отправьте событие открытия в API Revroute — в ответе придёт финальный целевой адрес.

Для этого выполните `POST`-запрос к эндпоинту `/track/open` с таким телом:

```json
{
  "deepLink": "https://yourdomain.link/short-link-slug"
}
```

При успешном запросе ответ будет JSON-объектом такой структуры:

```json
{
  "clickId": "ASltDhoxBiBqKH00",
  "link": {
    "id": "link_1K9XQTLF7OSH3Z48DKQ5WSRVY",
    "domain": "yourdomain.link",
    "key": "short-link-slug",
    "url": "https://yourapp.com/product/Apple-MacBook"
  }
}
```

Целевой адрес лежит в `link.url` — по нему можно открыть нужный экран приложения.

Ниже — полные примеры для React Native, iOS и Android.

<CodeGroup>

```javascript React Native
// DeepLinkTracker.js
async function trackDeepLinkClick(deepLink) {
  try {
    const response = await fetch(`https://api.revroute.ru/track/open`, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        deepLink,
      }),
    });

    if (response.ok) {
      const data = await response.json();
      const destinationUrl = data.link.url;

      // Navigate to the destination URL in your app
      navigateToDestination(destinationUrl);
    }
  } catch (error) {
    console.error("Error tracking deep link:", error);
  }
}
```

```swift iOS
// DeepLinkTracker.swift
func trackDeepLinkClick(deepLink: String) {
    let url = URL(string: "https://api.revroute.ru/track/open")!
    var request = URLRequest(url: url)
    request.httpMethod = "POST"
    request.setValue("application/json", forHTTPHeaderField: "Content-Type")

    let body = [
        "deepLink": deepLink,
    ]

    request.httpBody = try? JSONSerialization.data(withJSONObject: body)

    URLSession.shared.dataTask(with: request) { data, response, error in
        if let data = data,
           let json = try? JSONSerialization.jsonObject(with: data) as? [String: Any],
           let link = json["link"] as? [String: Any],
           let destinationUrl = link["url"] as? String {
            DispatchQueue.main.async {
                self.navigateToDestination(destinationUrl)
            }
        }
    }.resume()
}
```

```kotlin Android
// DeepLinkTracker.kt
private fun trackDeepLinkClick(deepLink: String) {
    val url = URL("https://api.revroute.ru/track/open")
    val connection = url.openConnection() as HttpURLConnection

    connection.requestMethod = "POST"
    connection.setRequestProperty("Content-Type", "application/json")
    connection.doOutput = true

    val body = JSONObject().apply {
        put("deepLink", deepLink)
    }

    connection.outputStream.use { os ->
        os.write(body.toString().toByteArray())
    }

    val response = connection.inputStream.bufferedReader().use { it.readText() }
    val jsonResponse = JSONObject(response)
    val link = jsonResponse.getJSONObject("link")
    val destinationUrl = link.getString("url")

    runOnUiThread {
        navigateToDestination(destinationUrl)
    }
}
```

### Сценарий 2: приложение не установлено

Если приложения нет, пользователь попадёт в App Store или Google Play — за это отвечает [таргетинг по устройствам](/help/managing-your-links/links/device-targeting), настроенный на шаге 2.

После установки и первого запуска в дело вступает [отложенный диплинкинг](/docs/concepts/deep-links/deferred-deep-linking). Приложению нужно:

1. Восстановить короткую ссылку, которая привела пользователя в магазин приложений
2. Отправить событие открытия через эндпоинт `/track/open`
3. Открыть финальный целевой адрес

<Note>
  Подробный разбор отложенного диплинкинга, включая работу с Install Referrer API
  в Google Play, — в руководстве [«Отложенные глубокие
  ссылки»](/docs/concepts/deep-links/deferred-deep-linking).
</Note>

## Тестирование диплинков

Перед выкаткой в продакшен проверьте диплинки на эмуляторах.

<Steps>

<Step title="Проверка на эмуляторе Android">

Для проверки на эмуляторе Android используйте Android Debug Bridge (adb):

```bash
adb shell am start -W -a android.intent.action.VIEW -d "https://yourdomain.link/your-short-link" com.yourpackage.name
```

</Step>

<Step title="Проверка на симуляторе iOS">

Для проверки на симуляторе iOS используйте команду `xcrun`:

```bash
xcrun simctl openurl booted "https://yourdomain.link/your-short-link"
```

</Step>

<Step title="Проверка на реальном устройстве">

Диплинк можно проверить и вручную, открыв его из мессенджера на телефоне:

1. Откройте мессенджер на устройстве
2. Отправьте себе сообщение со ссылкой-диплинком
3. Нажмите на ссылку в сообщении
4. Ссылка должна либо открыть приложение, либо увести в магазин приложений

</Step>

</Steps>

## Диагностика проблем с диплинками

Если диплинки работают не так, как ожидалось, начните с типовых причин.

<Steps>
<Step title="Домен диплинков не разрешён в приложении">

Убедитесь, что [домен диплинков внесён в конфигурацию приложения](/docs/concepts/deep-links/quickstart#разрешите-домен-диплинков-в-приложении). Без этого ни iOS, ни Android не распознают ссылки с вашего домена.

</Step>

<Step title="Система закешировала старую конфигурацию">

Если все шаги выполнены, а диплинки не работают, скорее всего iOS или Android держат в кеше старую конфигурацию.

Удалите и установите приложение заново — так система заново запросит файлы `apple-app-site-association` или `assetlinks.json`.

</Step>

<Step title="Ссылку обернул сторонний сервис">

Если ссылки рассылаются через маркетинговые платформы, почтовые сервисы или кликтрекеры, исходный адрес может быть обёрнут или изменён.

Когда сторонний сервис оборачивает ссылку Revroute в собственный трекинговый URL, диплинк не срабатывает: устройство видит домен обёртки, а не ваш разрешённый домен.

Попросите вашего провайдера рассылок или аналитики пропускать ссылки Revroute без изменений.

</Step>

</Steps>
