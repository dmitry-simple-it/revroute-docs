## Building your own integrations

You can build your own integrations with Revroute's link infrastructure using our API.

1. Read the documentation on how to create links or [track sale conversions](/docs/quickstart/server#tracking-sale-events).
2. Learn how to [integrate Revroute into your application](/docs/integrations/quickstart).
3. [Reach out to us](https://revroute.ru/contact/support) to feature your integration in the integrations marketplace.

## Integration webhooks

Revroute also supports webhooks for integrations. You can learn more about them in the [webhooks](/docs/webhooks) documentation.

Here's a list of the webhooks that Revroute supports:

- [`link.created`](/docs/webhooks/events) – when a new link is created
- [`link.updated`](/docs/webhooks/events) – when a link is updated
- [`link.deleted`](/docs/webhooks/events) – when a link is deleted
- [`link.clicked`](/docs/webhooks/events) – when a link is clicked
- [`lead.created`](/docs/webhooks/events) – when a new lead is created
- [`sale.created`](/docs/webhooks/events) – when a new sale is created
- [`partner.enrolled`](/docs/webhooks/events) – when a new partner is enrolled in your program
