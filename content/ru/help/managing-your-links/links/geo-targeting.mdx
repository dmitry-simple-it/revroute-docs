# Как использовать гео-таргетинг в RevRoute?

<Tip>
  Эта функция доступна только на [тарифах Pro и
  выше](https://revroute.ru/pricing).
</Tip>

Гео-таргетинг — мощная функция, позволяющая перенаправлять пользователей на разные ссылки в зависимости от их местоположения.

Это полезно для персонализации по местоположению. Например, можно перенаправлять пользователей из Великобритании на UK-версию лендинга, а остальных — на глобальную страницу.

Для использования нажмите кнопку **Таргетинг** в конструкторе ссылок. Откроется модальное окно «Таргетинг» — в нём, помимо гео-таргетинга, есть секции «iOS Таргетинг» и «Android Таргетинг».

Быстрый доступ — клавиша `G` в конструкторе (открывает модальное окно «Таргетинг»).

Для настройки в секции «Гео-таргетинг» укажите:

1. **Страна**: страна для таргетинга (названия стран в списке — на английском).
2. **URL**: URL перенаправления для пользователей из выбранной страны — поле рядом с выбором страны.

![Модальное окно «Таргетинг» с настройками гео-таргетинга и выбором страны](/images/ru/links/geo-targeting-modal.jpg)

Можно добавить несколько гео-таргетированных URL, нажав «Добавить локацию».

После добавления локаций и URL нажмите «Добавить таргетинг» для создания ссылки.

![Заполненное модальное окно «Таргетинг»: Germany → example.com/de, а также URL для iOS и Android](/images/ru/links/targeting-modal-filled.jpg)

При переходе по ссылке пользователи будут перенаправлены на указанный URL в зависимости от местоположения.

## Использование через RevRoute API

Гео-таргетированные ссылки можно создавать через [RevRoute API](/docs/api-reference/introduction).

Установите поле `geo` в [запросе создания ссылки](/docs/concepts/links/introduction). Поле `geo` — объект с [кодом страны](#список-кодов-стран) в качестве ключа и URL в качестве значения.

```json
{
  "url": "https://example.com",
  "geo": {
    "US": "https://example.com/us",
    "GB": "https://example.com/uk"
  }
}
```
