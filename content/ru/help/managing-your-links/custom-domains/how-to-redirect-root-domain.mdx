# Как настроить редирект для вашего пользовательского домена в RevRoute

<Tip>
  Эта функция доступна только на [тарифных планах Pro и
  выше](https://revroute.ru/pricing).
</Tip>

Когда вы добавляете пользовательский домен в рабочее пространство, его корневой адрес (домен без слага, например `go.acme-demo.ru`) по умолчанию никуда не перенаправляет — в списке доменов у такого домена отображается подпись «No redirect configured».

Обратите внимание: редирект корневого домена настраивается не в модалке «Обновить домен», а через редактирование корневой ссылки домена.

Чтобы перенаправить корневой домен на выбранный URL, выполните следующие шаги:

1. Если вы ещё этого не сделали, перейдите на [тарифный план Pro](https://revroute.ru/pricing).
2. Откройте страницу [**Настройки → Домены**](https://app.revroute.ru/settings/domains).
3. Нажмите кнопку `⋮` рядом с доменом, который хотите перенаправить — откроется выпадающее меню.

![Меню домена с разделами «Настройки ссылки» и «Настройки домена»](/images/ru/links/domain-row-menu.jpg)

4. В разделе «Настройки ссылки» выберите пункт **«Редактировать ссылку»** — откроется [конструктор ссылок RevRoute](/help/managing-your-links/additional-guides/link-builder) для корневой ссылки домена.
5. В поле **«URL назначения»** (отмечено бейджем PRO) введите адрес, на который должен перенаправлять ваш домен.

![Конструктор корневой ссылки домена с полем «URL назначения»](/images/ru/links/root-domain-redirect.jpg)

6. Нажмите **«Сохранить изменения»**. Корневой домен теперь будет перенаправлять на указанный URL, а подпись «No redirect configured» у домена в списке исчезнет.

## Расширенные функции ссылок

Кроме того, RevRoute предлагает множество расширенных функций для ваших ссылок корневого домена:

1. **Пользовательские превью ссылок**: Настройте отображение ваших ссылок в социальных сетях для повышения кликабельности.
2. **Теги**: Присваивайте теги вашим ссылкам для их организации. [Подробнее](/help/managing-your-links/links/how-to-use-tags).
3. **UTM-конструктор**: Добавляйте UTM-параметры к вашим ссылкам. [Подробнее](/help/managing-your-links/links/utm-builder).
4. **Маскировка ссылок**: Скрывайте целевой URL за вашей короткой ссылкой. [Подробнее](/help/managing-your-links/links/link-cloaking).
5. **Защита паролем**: Защищайте ваши ссылки паролем. [Подробнее](/help/managing-your-links/links/password-protected-links).
6. **Дата истечения**: Устанавливайте дату истечения срока действия ваших ссылок. [Подробнее](/help/managing-your-links/links/link-expiration).
7. **Таргетинг по устройствам**: Задавайте пользовательский URL назначения для устройств iOS и Android. [Подробнее](/help/managing-your-links/links/device-targeting).
8. **Гео-таргетинг**: Перенаправляйте пользователей на разные ссылки в зависимости от их местоположения. [Подробнее](/help/managing-your-links/links/geo-targeting).
9. **Индексация поисковыми системами**: Управляйте индексацией ваших ссылок поисковыми системами. [Подробнее](/help/managing-your-links/additional-guides/how-noindex-works).
10. **Комментарии**: Добавляйте комментарии к вашим ссылкам — для вас и вашей команды. [Подробнее](/help/managing-your-links/links/link-comments).
