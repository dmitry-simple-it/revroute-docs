# Migrating from Rebrandly

Rebrandly is a popular URL shortener that lets you create short links, which can be used in your marketing campaigns, social media posts, and more.

## How to migrate from Rebrandly to RevRoute

If you're looking to migrate from Rebrandly to RevRoute, we've built a custom migration tool that will help you migrate your links in a few simple steps.

<Steps>

<Step title="Get your Rebrandly API key">

First, log into your Rebrandly account and navigate to [Account > API](https://app.rebrandly.com/account/api).

<Image
  alt={`"Account > API" section in Rebrandly`}
  src="https://s3.revroute.ru/dub-public/assets/help/rebrandly-api-section.png"
/>

If you don't have an API key yet, click on "New API Key", which will create a new API key for you.

Copy the created API key. You'll need it in the next step.

![Copy the created API key](https://s3.revroute.ru/dub-public/assets/help/rebrandly-copy-api-key.png)

</Step>

<Step title="Use the Rebrandly migration tool">

If you haven't already, [create a workspace on RevRoute](/help/managing-your-workspace/what-is-a-workspace#how-to-create-a-workspace).

<Info>
  **Protip**: Once you create your workspace, we generally recommend that you **_not
  [configure your domain](/help/managing-your-links/custom-domains/how-to-add-custom-domain)_** until
  you've migrated all your links. This will prevent any potential downtime for
  your links.
</Info>

Then, open the import dialog with this direct link: [app.revroute.ru/links?import=rebrandly](https://app.revroute.ru/links?import=rebrandly). For now, the **⋮** menu on the Links page only offers CSV import.

Paste the API key you copied in the previous step into the **Rebrandly API Key** field and click **Confirm API Key**.

![Import from Rebrandly dialog: Rebrandly API Key field and Confirm API Key button](/images/ru/links/migration/import-rebrandly-modal.jpg)

Behind the scenes, we'll fetch all your Rebrandly custom domains and the number of links for each. You'll be presented with a list of domains that we've found.

</Step>

<Step title="Select the domains you want to migrate">

Select the domains you want to migrate. You can also choose if you'd like to import their respective tags as well. You can learn more about [how tags work on RevRoute](/help/managing-your-links/links/how-to-use-tags).

Once you're done, click **Confirm import**. In just a few seconds, all selected links and their tags will be migrated to RevRoute.

Once all your links have been imported, we will send you an email to let you know that the migration is complete.

</Step>

<Step title="Configure your domain">

Once you receive the email, you can [configure your domain](/help/managing-your-links/custom-domains/how-to-add-custom-domain#step-2-configure-your-domain) by setting the right DNS records. This will ensure that your links are pointing to RevRoute and not Rebrandly. Once you've done this, you can start using your links!

</Step>

</Steps>

<Tip>
  If the import doesn't start, export your links from Rebrandly to a CSV file and
  [import them from CSV](/help/managing-your-links/migration-guides/how-to-import-csv).
</Tip>


## Which Rebrandly link attributes are migrated?

Here's a list of attributes that are migrated from Rebrandly to RevRoute:

1. Destination URL
2. Short link slug
3. Link creation date
4. Link updated date
5. [Link tags](/help/managing-your-links/links/how-to-use-tags)
6. Link title (as part of RevRoute's Custom Link Previews feature)

Here are the attributes that are not migrated:

1. [Device targeting](/help/managing-your-links/links/device-targeting)
2. [Geo targeting](/help/managing-your-links/links/geo-targeting)
3. Deep links

If there are any attributes that you'd like to see migrated, please [send us an email](mailto:support@revroute.ru?subject=Rebrandly%20migration%20feedback) and let us know!
