# Как создать публичные дашборды аналитики в RevRoute

В RevRoute вы можете создать публичный дашборд аналитики для ваших коротких ссылок или папок ссылок.

Это позволяет делиться аналитикой по конкретной короткой ссылке (или папке ссылок) с клиентами или другими внешними заинтересованными сторонами, не приглашая их в ваше рабочее пространство RevRoute.

Для дополнительного контроля вы также можете показать [аналитику конверсий](#показать-аналитику-конверсий), [установить пароль](#установка-пароля) или [включить индексацию поисковыми системами](#индексация-поисковыми-системами) для дашборда.

В этом руководстве мы рассмотрим, как настроить публичные дашборды аналитики и доступные параметры.

## Создание публичного дашборда аналитики для короткой ссылки

Есть два способа включить публичный дашборд аналитики для конкретной короткой ссылки:

**Вариант 1**: В списке ссылок наведите курсор на счётчик кликов на карточке ссылки — появится всплывающее окно со статистикой. Нажмите в нём кнопку **Share dashboard**.

![Всплывающее окно со статистикой при наведении на счётчик кликов ссылки](/images/ru/links/share-hover-link-card.jpg)

**Вариант 2**: На странице аналитики примените фильтр по папке или ссылке — в панели инструментов появится кнопка **Share**. На общем дашборде без фильтра этой кнопки нет.

![Кнопка Share в панели инструментов аналитики при применённом фильтре по папке](/images/ru/links/analytics-filter-folder.jpg)

Затем в модальном окне **Share dashboard** включите тумблер **Enable public sharing**.

![Модальное окно Share dashboard](/images/ru/links/share-dashboard-modal.jpg)

RevRoute сразу создаст публичную страницу аналитики и автоматически скопирует ссылку на неё в буфер обмена. [Вот пример](https://app.revroute.ru/share/dash_1M31V51R8RART9SCEZNY6601D).

![Публичный дашборд аналитики RevRoute](/images/ru/links/share-public-dashboard.jpg)

## Создание публичного дашборда аналитики для папки ссылок

<Tip>Только владельцы рабочего пространства могут создавать публичные дашборды для папок ссылок.</Tip>

Есть два способа включить публичный дашборд аналитики для конкретной папки ссылок:

**Вариант 1**: В списке папок откройте меню `⋮` нужной папки и выберите **Поделиться аналитикой**.

![Меню папки с пунктом «Поделиться аналитикой»](/images/ru/links/folder-row-menu.jpg)

**Вариант 2**: Так же, как и для короткой ссылки: на странице аналитики примените фильтр по нужной папке — в панели инструментов появится кнопка **Share**.

Затем в том же модальном окне **Share dashboard** включите тумблер **Enable public sharing**.

## Настройки общего доступа

Следующие настройки доступны как для коротких ссылок, так и для папок ссылок.

### Показать аналитику конверсий

Если включить тумблер **Conversion analytics**, на публичном дашборде будут отображаться данные о лидах и продажах.

Вот как выглядит дашборд с включённой аналитикой конверсий:

![Публичный дашборд с включённой аналитикой конверсий](/images/ru/links/share-public-dashboard.jpg)

При выключенном **Conversion analytics** публичный дашборд показывает только клики.

### Установка пароля

Вы также можете установить пароль для публичного дашборда аналитики для дополнительной защиты страницы. Для этого в том же модальном окне **Share dashboard** включите тумблер **Password protection**, задайте пароль в появившемся поле и нажмите **Save changes**.

Когда кто-то откроет публичный дашборд аналитики, он увидит запрос пароля — без пароля страница не откроется.

### Индексация поисковыми системами

Если вы хотите включить индексацию поисковыми системами для вашего публичного дашборда аналитики, включите тумблер **Search engine indexing** и нажмите **Save changes**.

Это сделает страницу более доступной для обнаружения поисковыми системами, такими как Google.

В противном случае публичные дашборды аналитики по умолчанию содержат мета-тег `noindex`, который указывает поисковым системам не индексировать страницу.

`html <meta name="robots" content="noindex, nofollow" />`

## Как отключить публичный дашборд аналитики

Выполните те же шаги, что и в разделе [«Создание публичного дашборда аналитики для короткой ссылки»](#создание-публичного-дашборда-аналитики-для-короткой-ссылки) выше, но выключите тумблер **Enable public sharing**.

RevRoute автоматически отключит публичную страницу аналитики для данной ссылки. Вы по-прежнему сможете просматривать аналитику ссылки в панели управления RevRoute, но публичная страница больше не будет доступна.

<Warning>
  Внимание: При отключении публичного дашборда аналитики для данной ссылки ваша
  существующая ссылка на дашборд перестанет работать, и вам придётся создать новую,
  которая будет иметь другой URL. Это действие необратимо.
</Warning>
