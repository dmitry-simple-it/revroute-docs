В рабочем пространстве Revroute вы можете экспортировать ссылки в CSV-файл. Это полезно, если вы хотите проанализировать данные локально или поделиться ими с внешними заинтересованными лицами.

Чтобы экспортировать ссылки, выполните следующие шаги:

<Steps>

<Step title="Откройте модальное окно экспорта ссылок">

    В рабочем пространстве Revroute перейдите на вкладку **Links**.

    Затем нажмите кнопку `⋮`, чтобы открыть выпадающее меню дополнительных действий. Выберите опцию **Export links**.

    ![Нажмите на выпадающее меню для открытия модального окна экспорта ссылок](https://s3.revroute.ru/dub-public/assets/help/links-dashboard-dropdown.png)

</Step>

<Step title="Выберите диапазон дат">

    Выберите диапазон дат для ссылок, которые хотите экспортировать. По умолчанию Revroute экспортирует все ссылки.

    ![Выберите диапазон дат для экспортируемых ссылок](https://s3.revroute.ru/dub-public/assets/changelog/export-links.png)

</Step>

<Step title="Выберите столбцы для экспорта">

    По умолчанию Revroute экспортирует следующие столбцы:
    - Short link
    - Destination URL
    - Clicks
    - Created at

    Вы можете выбрать столбцы для экспорта в разделе **Columns**.

    ![Выберите столбцы для экспорта](https://s3.revroute.ru/dub-public/assets/help/export-links-columns.png)

</Step>

<Step title="Примените текущие фильтры" optional>

    При желании вы можете применить текущие фильтры к экспортируемым ссылкам. Если вы это сделаете, Revroute экспортирует ссылки, соответствующие текущим фильтрам; в противном случае будут экспортированы все ссылки.

    ![Примените текущие фильтры к экспортируемым ссылкам](https://s3.revroute.ru/dub-public/assets/help/export-links-columns-with-filters.png)

</Step>

<Step title="Скачайте данные">

    После выбора диапазона дат и столбцов для экспорта нажмите **Export links**.

    Через несколько секунд CSV-файл будет загружен на ваш компьютер.

</Step>

</Steps>
