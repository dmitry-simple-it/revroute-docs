# Управление ссылками с помощью папок

<Tip>
  Эта функция доступна только на [тарифах Pro и
  выше](https://revroute.ru/pricing).
</Tip>

Папки — отличный способ организации и управления доступом к ссылкам в RevRoute.

С помощью папок вы можете:

1. **Организовать ссылки по маркетинговым каналам**. Например, если вы используете RevRoute для [партнёрской программы](https://revroute.ru/) и SMS-маркетинга, создайте отдельные папки, чтобы эти ссылки не загромождали основной дашборд.
2. **Управлять доступом к ссылкам в команде**. Например, если в рабочем пространстве RevRoute есть маркетинговые команды из разных отделов, создайте папки для каждой с [управлением доступом на основе ролей](/help/managing-your-links/links/folders-rbac).

![Папки ссылок](/images/ru/links/folders-page.jpg)

В этом руководстве мы рассмотрим использование папок для организации ссылок в RevRoute.

## Создание папки

Есть несколько способов создать папку:

<Steps>
<Step title="На дашборде ссылок">
Откройте переключатель папок рядом с заголовком дашборда и выберите **Создать папку**:

![Новая папка на дашборде](/images/ru/links/new-folder-link-dashboard.jpg)
</Step>

<Step title="В конструкторе ссылок">
Создайте папку из селектора **Папка** в [конструкторе ссылок](/help/managing-your-links/additional-guides/link-builder):

![Новая папка в конструкторе](/images/ru/links/new-folder-link-builder.jpg)
</Step>

<Step title="В библиотеке папок">
Создайте папку в [библиотеке папок](https://app.revroute.ru/settings/library/folders), нажав кнопку **Create folder** (или клавишу `C`).
</Step>
</Steps>

Создание папки просто. Сначала задайте имя:

![Создание новой папки](/images/ru/links/create-new-folder.jpg)

Затем выберите [права доступа на уровне пространства](/help/managing-your-links/links/folders-rbac) и нажмите **Создать папку**:

![Доступ к папке](/images/ru/links/create-new-folder-access.jpg)

## Добавление ссылок в папку

Выберите папку в селекторе **Папка** на странице редактирования ссылки и нажмите **Сохранить изменения**.

Также можно переместить ссылку прямо с дашборда: откройте меню `⋮` ссылки и выберите **Переместить** (или клавишу `M`):

![Меню ссылки](/images/ru/links/link-row-menu.jpg)

В открывшемся окне выберите папку назначения:

![Перемещение ссылки в папку](/images/ru/links/move-link-folder.jpg)

Или используйте [массовые действия](/help/managing-your-links/links/bulk-link-actions) для перемещения нескольких ссылок:

![Массовое перемещение](/images/ru/links/move-link-folder-bulk.jpg)

## Установка папки по умолчанию

Выберите папку, которая будет отображаться по умолчанию при открытии дашборда.

В [библиотеке папок](https://app.revroute.ru/settings/library/folders) откройте меню `⋮` у папки и выберите **Сделать по умолчанию** (или клавишу `D`):

![Меню папки](/images/ru/links/folder-row-menu.jpg)

## Сколько папок можно создать?

Количество папок зависит от тарифа:

- **Pro**: До 3 папок
- **Business**: До 20 папок
- **Advanced**: До 50 папок
- **Enterprise**: Неограниченно

Подробнее на [странице тарифов](https://revroute.ru/pricing).

## Программное управление папками

Создавать, обновлять, удалять папки и получать их список можно через [RevRoute API](/docs/api-reference/introduction) — аутентификация и формат запросов описаны в [справочнике API](/docs/api-reference/authentication).
