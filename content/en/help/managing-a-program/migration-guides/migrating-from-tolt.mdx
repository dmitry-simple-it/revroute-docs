# Migrating from Tolt

<Tip>
  RevRoute Partners is only available on [Business plans and
  above](https://revroute.ru/pricing).
</Tip>

Tolt is an affiliate management platform often chosen by early-stage companies.

If you're moving your program to [RevRoute Partners](https://revroute.ru/), here's what you get:

1. **Partner payouts in rubles**: RevRoute [pays your partners](/help/managing-a-program/sending-payouts/partner-payouts) for you — to Russian bank cards or via SBP (the Faster Payments System).
2. **Flexible rewards**: [3 reward types](/help/managing-a-program/rewards-and-commissions/partner-rewards#configuring-reward-types) — per click, per lead, and per sale (flat or percentage), [reward conditions](/help/managing-a-program/rewards-and-commissions/partner-rewards#adding-reward-conditions) — e.g. a higher rate for customers from a specific country — and [bounties](/help/managing-a-program/engaging-partners/program-bounties).
3. **Analytics**: [conversion tracking](/docs/concepts/attribution) and stats by source, device, and country, including [natural-language queries](/help/managing-your-links/analytics/analytics-overview#bonus-ask-ai-feature).
4. **Embedded referral dashboard** (Advanced plan and above): [embed a referral dashboard right in your app](/docs/partners/embedded-referrals).
5. **Offer marketplace** (Enterprise plan): your program is listed in the [RevRoute catalogue](https://revroute.ru/for-partners), where partners find and join offers themselves.

In this article, we'll learn how to import your Tolt affiliate program to [RevRoute Partners](/help/managing-a-program/partners-overview) for a more powerful, scalable, and branded partner management experience.

## How to migrate from Tolt to RevRoute?

If you're looking to migrate from Tolt to RevRoute Partners, we've built a custom migration tool that will help you migrate everything over in just 2-3 clicks – without breaking any existing Tolt affiliate links.

<Steps>
<Step title="Add a custom domain to your RevRoute workspace">
Before starting the migration process, you'll need to add a custom domain to RevRoute. This domain will be used to create short links for each affiliate link that we import from Tolt.

If you haven't added a custom domain to RevRoute yet, you can [follow this guide to set that up](/help/managing-your-links/custom-domains/how-to-add-custom-domain).

</Step>

<Step title="Set up conversion tracking + client-side click-tracking">

Next, [set up conversion tracking](/docs/quickstart/server) to track signup and sale events. We also have some [in-app guides that you can reference here](https://app.revroute.ru/guides).

For backward compatibility, we also recommend setting up client-side click-tracking when installing the RevRoute Analytics script on your site. This will ensure all your existing `domain.com?via=affiliate` links will keep working as expected, which gives affiliates time to update their links to the new format.

The [client-side installation guide](/docs/quickstart/client) walks through enabling click tracking for your RevRoute short links.

</Step>

<Step title="Get your Tolt API Key and Program ID">
[Follow this guide](https://docs.tolt.com/authentication) to get your Tolt API key – API keys can be created in the [Settings → Integrations](https://app.tolt.io/settings?tab=integrations) tab of your Tolt dashboard:

![Tolt API key](https://s3.revroute.ru/dub-public/assets/cms/tolt-api-key.png)

You will also need to get your Tolt Program ID under [Program Settings](https://app.tolt.io/program-settings?page=general-settings):

![Tolt Program ID](https://s3.revroute.ru/dub-public/assets/cms/tolt-program-id.png)

We will use the API key and Program ID to retrieve and import your existing Tolt affiliate program to RevRoute.

</Step>

<Step title="Import your Tolt program">

Once you've [set up your RevRoute partner program](/help/managing-a-program/getting-started/setting-up-your-program), open the import dialog with this direct link: [app.revroute.ru/program/partners?import=tolt](https://app.revroute.ru/program/partners?import=tolt). For now, the **Partners** section menu doesn't have an import option.

![Tolt import dialog: Tolt API Key and Tolt Program ID fields](/images/ru/program/migration/import-tolt-modal.jpg)

Enter your **Tolt API Key** and **Tolt Program ID**, then click **Fetch program**.

</Step>

</Steps>

## What data is migrated?

Our Tolt migration tool imports the following attributes to RevRoute Partners:

### Affiliates / Partners

To ensure the efficiency of your partner program, we automatically filter out dormant affiliates and only import the ones that both:

- Are in an "active" state
- Have at least 1 lead / referral

We also automatically import all your affiliates' links and recreate them in RevRoute using your program's domain and default URL.

<Info>
Since Tolt doesn't expose a `/rewards` endpoint, your Tolt program terms will not be migrated – all partners will be assigned to your program's default reward.

Learn more about how [Partner rewards](/help/managing-a-program/rewards-and-commissions/partner-rewards) work on RevRoute.

</Info>

### Referrals / Customers

By default, we import all referrals that are associated with an affiliate in your Tolt program. This ensures that all subsequent subscription renewal events will continue to be tracked on RevRoute.

<Warning>
  Some referrals might not have a valid billing-system customer ID yet. They
  will still be imported, with the customer ID filled in once the next billing
  event arrives.
</Warning>

### Commissions

We also import all commissions associated with any customers that were imported above. Depending on the commission state on Tolt, they will be marked accordingly on RevRoute as well:
| Tolt | RevRoute |
| --- | --- |
| `Pending` | `Pending` |
| `Approved` | `Pending` |
| `Paid` | `Paid` |
| `Rejected` | `Canceled` |
| `Refunded` | `Refunded` |

RevRoute also supports 3 additional commission states:

- `Fraud`: Useful for marking a sale as fraudulent and excluding it from any future payouts.
- `Processed`: When a commission has been added to a [payout](/help/managing-a-program/sending-payouts/partner-payouts) (after any applicable holding period).
- `Duplicate`: Useful for marking if a commission was rewarded more than once and needs to be marked as a duplicate event.

<Warning>
  Commissions for referrals that do not have a valid billing-system customer ID or a
  transaction trace will not be imported.
</Warning>

If there are any other attributes that you'd like to see migrated (or if you would like to customize any of the rules above), please [send us an email](mailto:support@revroute.ru?subject=Tolt%20migration%20feedback) to let us know!

## Next steps

After importing your program, here are some recommended next steps:

### 1. Set up your bank account for partner payouts

RevRoute Partners supports [1-click payouts](/help/managing-a-program/sending-payouts/partner-payouts): earnings are aggregated and paid out in rubles through the built-in payment infrastructure.


RevRoute pays partners through its built-in payment infrastructure — by Russian bank card or SBP. See [how to top up your payout balance](/help/managing-a-program/sending-payouts/how-to-set-up-bank-account) before running your first payout batch.

### 2. Notify your affiliates about the platform change

Next, you'll want to reach out to your existing partners and let them know about the platform change. To do that, you can send them an email with the following example verbiage:

> Hey,
>
> Starting today, we are switching the [Your Company] Affiliate Program from Tolt to [RevRoute Partners](https://revroute.ru/).
>
> To get started, follow these steps:
>
> 1. Sign up for a RevRoute Partners account here: `partners.revroute.ru/{your_program_slug}/register`
> 2. [Connect a payout method](https://partners.revroute.ru/settings/payouts) to receive your commissions.
> 3. Start sharing your shiny new referral link with your audience 🚀
>
> Let us know if you have any questions!
