# Managing links with folders

<Tip>
  This feature is only available on [Pro plans and
  above](https://revroute.ru/pricing).
</Tip>

Folders are a great way to organize and manage access to your links on RevRoute.

With folders, you can:

1. **Organize links by marketing channels**. E.g. if you're using RevRoute for both your [affiliate program](https://revroute.ru/) and for SMS marketing, you can create folders for both so those links doesn't clutter your main links dashboard.
2. **Manage access to links across your team**. E.g. if you have marketing teams from different departments within your RevRoute workspace, you can create folders for each team with [role-based access controls](/help/managing-your-links/links/folders-rbac) to ensure members can only see the links that they should have access to.

![Link folders](/images/ru/links/folders-page.jpg)

In this guide, we'll walk through how to use folders to organize and manage access to your links on RevRoute.

## Creating a folder

There are a few ways you can create a new folder:

<Steps>
<Step title="In your links dashboard">
You can quickly create a new folder within your links dashboard:

![New folder links dashboard](/images/ru/links/new-folder-link-dashboard.jpg)
</Step>

<Step title="In the link builder">
You can also create a new folder directly inside the [link builder](/help/managing-your-links/additional-guides/link-builder):

![New folder link builder](/images/ru/links/new-folder-link-builder.jpg)
</Step>

<Step title="In the folder library">
Last but not least, you can also create a folder inside your [folder library](https://app.revroute.ru/settings/library/folders) by clicking the **Create folder** button (or pressing `C`).
</Step>
</Steps>

Creating a folder is fairly simple. First, give it a name:

![Create new folder](/images/ru/links/create-new-folder.jpg)

Then, you can also choose the [workspace-level permission](/help/managing-your-links/links/folders-rbac) for the folder:

![Create new folder access](/images/ru/links/create-new-folder-access.jpg)

## Adding links to a folder

To add links to a folder, simply select the folder you want to move the link to within the link edit page and click "Save changes":

![Move link to folder](/images/ru/links/move-link-folder.jpg)

Alternatively, you can also move a link to a folder directly within the links dashboard:

![Move link to folder shortcut](/images/ru/links/link-row-menu.jpg)

Last but not least, you can use [bulk link actions](/help/managing-your-links/links/bulk-link-actions) to move multiple links to a folder at once:

![Move link to folder bulk](/images/ru/links/move-link-folder-bulk.jpg)
## Setting a default folder

Once you've created a few folders, you can choose one to show up by default when you open your links dashboard.

To do that, open the `⋮` dropdown next to the folder in your [folder library](https://app.revroute.ru/settings/library/folders) and select the "Set as Default" option (or press `D`):

![Set default folder](/images/ru/links/folder-row-menu.jpg)

## How many folders can I create?

The number of folders you can create depends on your plan:

- **Pro plan**: Up to 3 folders
- **Business plan**: Up to 20 folders
- **Advanced plan**: Up to 50 folders
- **Enterprise plan**: Unlimited folders

Check out our [pricing page](https://revroute.ru/pricing) for more information on our plans.

## Managing folders programmatically

You can also manage folders programmatically using the RevRoute API: create, update,
delete and list folders, then assign links to them. See [Organizing links](/docs/concepts/links/organization)
for how folders relate to tags and access control.
