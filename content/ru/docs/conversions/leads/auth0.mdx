## Настройка Auth0

Далее настройте Auth0 для отслеживания событий конверсий лидов.

Вот как это работает в двух словах:

1. В функции `afterCallback` при входе проверьте, новый ли это пользователь.
2. Если пользователь новый — проверьте, есть ли cookie `rr_id`.
3. Если cookie есть — отправьте событие лида в Revroute через `dub.track.lead`.
4. Удалите cookie `rr_id`.

```typescript app/api/auth/[auth0]/route.js
import { handleAuth, handleCallback, type Session } from "@auth0/nextjs-auth0";
import { cookies } from "next/headers";
import { dub } from "@/lib/dub";

const afterCallback = async (req: Request, session: Session) => {
  const userExists = await getUser(session.user.email);

  if (!userExists) {
    createUser(session.user);
    // check if rr_id cookie is present
    const clickId = cookies().get("rr_id")?.value;
    if (clickId) {
      // send lead event to Revroute
      await dub.track.lead({
        clickId,
        eventName: "Sign Up",
        customerExternalId: session.user.id,
        customerName: session.user.name,
        customerEmail: session.user.email,
        customerAvatar: session.user.image,
      });
      // delete the rr_id cookie
      cookies().set("rr_id", "", {
        expires: new Date(0),
      });
    }
    return session;
  }
};

export default handleAuth({
  callback: handleCallback({ afterCallback }),
});
```
