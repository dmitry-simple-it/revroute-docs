# Скриншоты интерфейса RevRoute (RU)

Единое место всех перезахваченных кадров базы знаний. Снимаются с демо-воркспейсов
CloudFlow (`cloudflow-demo`) и Acme (`acme-demo`) — только вымышленные данные, суммы в ₽.

## Структура и именование

```
public/images/ru/<раздел>/<суть-кадра>.jpg          — одиночный кадр
public/images/ru/<раздел>/<сценарий>-step-<N>.jpg   — шаг галереи <StepGallery>
public/images/ru/<раздел>/<подпапка>/…              — крупные серии (например program/setup/)
```

- `<раздел>` повторяет раздел справки: `links`, `program`, `analytics`, `workspace`, …
- имена — kebab-case, по сути кадра, а не по странице: `partner-details.jpg`,
  `link-builder.jpg`, `setup-step-2-rewards.jpg`;
- формат: JPEG 1399×868 (захват вьюпорта 1424×884 через мост расширения — см. память
  kb-media-recapture), светлая тема, без личных данных;
- кадр используется из MDX по абсолютному пути `/images/ru/...`; alt — по-русски.

## Правила

1. Один кадр — одно место на диске; переиспользуем путём, а не копией.
2. Заменяя кадр, сохраняйте имя файла (кэш чистится хешем содержимого на прод-сборке
   не автоматически — при смысловой замене лучше новое имя + правка MDX).
3. Осиротевшие кадры ловит `npm run check:images` (битые ссылки) и скрипт поиска
   сирот из рефакторинга; не оставляйте файлы без ссылок.
4. Новые расхождения продукта с доками, замеченные при съёмке, — в реестр:
   `D:\revroute-os\20-product\platform\qa\product-findings-registry.md`.
