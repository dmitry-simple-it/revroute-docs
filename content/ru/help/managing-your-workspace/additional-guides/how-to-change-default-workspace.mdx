# Как изменить рабочее пространство по умолчанию в RevRoute?

В RevRoute вы можете установить [выбранное рабочее пространство](/help/managing-your-workspace/what-is-a-workspace) в качестве рабочего пространства по умолчанию. Это то пространство, которое открывается при [входе в RevRoute](https://app.revroute.ru).

При создании первого рабочего пространства в RevRoute оно автоматически устанавливается как пространство по умолчанию. Однако вы можете изменить его в любое время.

Вот как изменить рабочее пространство по умолчанию в RevRoute:

1. Откройте [настройки аккаунта](https://app.revroute.ru/account/settings): нажмите на аватар в левом нижнем углу и выберите **Настройки аккаунта**.
2. Прокрутите страницу до раздела **Рабочее пространство по умолчанию**.
3. Выберите рабочее пространство в выпадающем списке. Если пространств много, воспользуйтесь поиском над списком (его подсказка пока на английском).

![Раздел «Рабочее пространство по умолчанию» с открытым списком пространств](/images/ru/workspace/account-default-workspace.jpg)

4. Нажмите **Сохранить изменения**.

Готово! При следующем входе в RevRoute откроется выбранное рабочее пространство.
