# Managing partner commissions

<Tip>
  This feature is only available on [Business plans and
  above](https://revroute.ru/pricing).
</Tip>

## Where to find your program commissions?

In the program menu, open **Commissions** under **Insights**. The top of the page summarizes how many commissions you have and for what amount — in total, pending, processed, and paid. Below is the table of all program commissions with a filter and a date range picker.

![Commissions page: status summary and the commissions table](/images/ru/program/commissions/commissions-page.jpg)

| Column      | Data                                                                         |
| ----------- | ---------------------------------------------------------------------------- |
| Date        | Commission date                                                              |
| Customer    | The customer associated with the lead or sale                                |
| Partner     | The partner receiving the commission                                         |
| Type        | Click, lead, sale, referral, or "Other" — the label for manual one-time commissions |
| Sale amount | The sale amount, or a count for clicks, leads, and manual commissions        |
| Commission  | The amount the partner will receive                                          |
| Status      | The current commission status — see [below](#commission-statuses)            |

Use the gear button in the table header to choose columns — for example, add **Group**. To download commissions, use the **⋮** menu → **Export as CSV**.

## Commission statuses

A new commission moves through these statuses:

- **Pending** — the initial status. The commission waits for the partner group's [payout holding period](/help/managing-a-program/sending-payouts/partner-payouts#payout-holding-period) — from zero to 90 days.
- **Processed** — the holding period is over and the commission is available for payout.
- **Paid** — the payout containing this commission has been sent.

A commission can also get one of these statuses:

- **Refunded** — the sale behind the commission was refunded. Set automatically when your billing system passes the refund event (YooKassa or a custom integration), or via the [RevRoute API](/docs/api-reference/introduction).
- **Fraud** — the commission was deemed fraudulent.
- **Duplicate** — the commission was deemed a duplicate and excluded from all upcoming payouts.
- **Canceled** — the commission was canceled, e.g. for a self-referral sale.
- **On hold** — the commission is paused, e.g. while [fraud events](/help/managing-a-program/insights-and-reporting/fraud-detection) are being reviewed.

To mark a commission manually, use the **⋯** menu on its row: **Mark as duplicate**, **Mark as fraud**, or **Cancel commission**. RevRoute asks you to confirm — **the action can't be undone**. Marking as fraud and canceling can be applied to all past and future commissions of the same customer–partner pair.

![Commission menu: Mark as duplicate, Mark as fraud, Cancel commission](/images/ru/program/commissions/commission-row-menu.jpg)

## Creating manual commissions

Sometimes you need to create a commission manually — e.g. to pay a bonus or account for a sale missed due to a tracking error. Manual commissions are included in the partner's next payout.

Click **Create commission** (or press `C`) on the **Commissions** page or in a partner's profile. In the **Create commission** sheet, pick the partner and the commission type: **One-time**, **Lead**, or **Recurring sale**.

### One-time commissions

A bonus, reimbursement, or any other payout not tied to a customer, referral link, or sale.

![Create commission sheet: a one-time 5,000 ₽ commission for MediaPro](/images/ru/program/commissions/commission-create-onetime.jpg)

| Field           | Description                              | Required |
| --------------- | ---------------------------------------- | -------- |
| Amount          | The commission amount in rubles          | ✅       |
| Description     | An optional description, up to 190 characters | ❌  |
| Set custom date | The commission date; defaults to today   | ❌       |

### Lead commissions

A reward for a qualified sign-up or referral. The amount is calculated automatically from the [lead reward](/help/managing-a-program/rewards-and-commissions/partner-rewards) of the partner's group.

| Field                      | Description                                                                          | Required |
| -------------------------- | ------------------------------------------------------------------------------------ | -------- |
| Referral link              | The partner link the lead is tied to                                                 | ✅       |
| Customer                   | The customer associated with the lead; you can [create a new one right here](#creating-a-new-customer) | ✅ |
| Set custom lead event date | The event date; defaults to today                                                    | ❌       |
| Set custom lead event name | The lead event name                                                                  | ❌       |

### Recurring sale commissions

A reward for a subscription payment by a referred customer. The commission is calculated from the [sale reward](/help/managing-a-program/rewards-and-commissions/partner-rewards) once you enter the sale amount.

![Create commission sheet: Recurring sale type](/images/ru/program/commissions/commission-create-sale.jpg)

| Field         | Description                                                                                                                  | Required                |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| Referral link | The partner link the sale is tied to; available once a partner is selected                                                  | ✅                      |
| Customer      | The customer associated with the sale                                                                                        | ✅                      |
| Event source  | **Create new event** — a new sale for the partner, e.g. a one-time purchase; **Import from Stripe** — the customer's paid Stripe invoices | ✅ |
| Sale amount   | The sale amount                                                                                                              | ✅ for a new event      |
| Set sale date | The sale date; defaults to today                                                                                             | ❌                      |
| Invoice ID    | The sale's invoice ID — can be used to retrieve the commission via the API                                                  | ❌                      |
| Product ID    | The ID of the product sold                                                                                                   | ❌                      |

### Creating a new customer

If the customer doesn't exist in RevRoute yet, click **Create new customer** in the **Customer** list to open the customer dialog.

![Create new customer dialog](/images/ru/program/commissions/commission-new-customer.jpg)

| Field            | Description                                                                  | Required |
| ---------------- | ---------------------------------------------------------------------------- | -------- |
| Name             | The customer's name                                                          | ❌       |
| Email            | The customer's email                                                         | ❌       |
| Country          | The customer's country — used in analytics and country-specific rewards      | ✅       |
| External ID      | Your unique ID for this customer — e.g. your database ID or email            | ✅       |
| stripeCustomerId | The customer's Stripe ID — needed to import Stripe invoices                  | ❌       |

Once created, you can attach commissions to the customer.

## Creating clawbacks

If a partner was credited too much, create a clawback — a negative commission deducted from the partner's next payout.

Open the **⋮** menu next to **Create commission** and select **Create clawback**.

![Commissions page menu: Create clawback and Export as CSV](/images/ru/program/commissions/commissions-menu.jpg)

In the **Create clawback** sheet, set:

- **Partner** — the partner the amount is withheld from;
- **Amount** — the clawback amount;
- **Reason** — order canceled, fraud, terms violation, tracking error, payment failed, ineligible partner, duplicate commission, or other.

Click **Create clawback** — it appears in the commissions table as a negative commission.
