# How to import links from a CSV file

You can also import your existing links into RevRoute via our CSV import feature. This is useful if you have a large list of links to import or if you want to [import links from another provider](/help/managing-your-links/migration-guides/migrating-from-bitly) that we don't have a 1-click importer for.

To import your links, you can follow these steps:

<Steps>

<Step title="Prepare your CSV file">

Before you import your CSV file, make sure it is in the correct format. Your CSV file needs to have the following data:

| RevRoute field  | Required | Description                                                    | Example                   |
| --------------- | -------- | -------------------------------------------------------------- | ------------------------- |
| Destination URL | **Yes**  | The destination URL of the link you want to import.            | `https://www.google​.com` |
| Short link      | **Yes**  | The shortened version of the link.                             | `yourdomain.com/abc123`   |
| Title           | No       | The title of the link.                                         | `Google`                  |
| Description     | No       | The description of the link.                                   | `Search the web`          |
| Tags            | No       | The tags of the link – must be a comma-separated list of tags. | `search, google, web`     |
| Creation date   | No       | The date the link was created.                                 | `2024-01-01`              |

The actual names of your columns can be anything you want, but you need to make sure that the required columns are present.

</Step>

<Step title="Upload your CSV file">

If you haven't already, [create a workspace on RevRoute](/help/managing-your-workspace/what-is-a-workspace).

<Info>
  **Protip**: Once you create your workspace, we generally recommend that you **_not
  [configure your domain](/help/managing-your-links/custom-domains/how-to-add-custom-domain)_** until
  you've migrated all your links. This will prevent any potential downtime for
  your links.
</Info>

Then, on the [Links page](https://app.revroute.ru/links), click the **⋮** button to the right of the search box and select **Import from CSV**.

![Links page ⋮ menu: Import from CSV and Export as CSV](/images/ru/links/migration/links-import-menu.jpg)

This will open a modal with a file uploader.

![Import links from a CSV file dialog with the upload area](/images/ru/links/migration/import-csv-modal.jpg)

Upload your CSV file, and you should be automatically redirected to the next step.

</Step>

<Step title="Review the AI-generated column mappings">

When you upload a CSV file, RevRoute uses AI to map the columns in your file to the supported data fields in RevRoute: CSV columns on the left, RevRoute fields on the right. Required fields are marked with an asterisk.

![Mapping CSV columns to RevRoute fields before import](/images/ru/links/migration/import-csv-mapping.jpg)

You can then review and edit the mappings before selecting **Confirm import**. In just a few seconds, all your links will be migrated to RevRoute.

Alternatively, you can also select **Choose another file** to upload a different CSV file.

</Step>

<Step title="Review the import summary">

Once all your links have been imported, we will send you an email to let you know that the import is complete. If there are any issues with some of the links, we will send you a separate email with the details of the errors.

</Step>

<Step title="Configure your domain">

Once all your links are imported, you can [configure your domain](/help/managing-your-links/custom-domains/how-to-add-custom-domain#step-2-configure-your-domain) by setting the right DNS records. Once this is done, you can start using your links!

</Step>

</Steps>
