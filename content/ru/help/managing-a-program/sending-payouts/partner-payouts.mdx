<Tip>
  Эта функция доступна на [тарифах Business и выше](https://revroute.ru/pricing).
</Tip>

Revroute Partners поддерживает выплаты партнёрам в один клик (или полностью автоматически) через [ЮКассу Payouts](https://yookassa.ru/developers/payouts), экономя более 40 часов в месяц.

Если у вас сотни партнёров, не нужно вручную отправлять каждую выплату и беспокоиться о сбоях. Revroute платит партнёрам в один клик, готовит документы для бухгалтерии и логирует все события.

## Поддерживаемые методы выплат

Revroute использует ЮКассу Payouts для перевода комиссий партнёрам. Поддерживаются следующие способы получения:

| Метод           | Описание                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------- |
| **Банковская карта** | Российская карта (Мир, Visa/Mastercard российских банков). Партнёр сохраняет карту через виджет выплат ЮКассы. |
| **СБП**         | Система быстрых платежей — перевод по номеру телефона в один из поддерживаемых банков (см. `GET /v3/sbp_banks`). |

<Note>
  Выплаты отправляются в **рублях (RUB)**. Карты иностранных банков для выплат
  не поддерживаются.
</Note>

## Налоги

Партнёры в России самостоятельно платят налоги. Чаще всего это одна из категорий:

- **Самозанятый (НПД)** — партнёр формирует чек в приложении «Мой налог» на каждую выплату. Налог: 4% (с физлиц) / 6% (с юрлиц).
- **ИП** — партнёр сам отчитывается по своей системе налогообложения.
- **Физическое лицо** — ваша компания выступает налоговым агентом и обязана удержать и перечислить НДФЛ.

<Warning>
  Revroute не удерживает и не перечисляет налоги за партнёра. Соберите
  у партнёра его налоговый статус (`profileType` в профиле партнёра) и
  настройте соответствующий процесс в бухгалтерии.
</Warning>

## Панель управления выплатами

Перейдите на вкладку **Partner Program** → страница **Payouts**.

![Вкладка выплат](https://s3.revroute.ru/dub-public/assets/cms/partner-payouts-location.png)

В верхней части — сводка по ожидающим и завершённым выплатам:

![Сводка по выплатам](https://s3.revroute.ru/dub-public/assets/cms/payout-summary-header.png)

**Pending payouts** — общая сумма комиссий, готовых к выплате.

При наведении видно:

- **Eligible payouts** — комиссии партнёров, [настроивших метод выплат](/help/partnering-with-programs/receiving-payouts/receiving-payouts).
- **Ineligible payouts** — комиссии партнёров, ещё [не настроивших метод выплат](/help/partnering-with-programs/receiving-payouts/receiving-payouts).

Когда есть хотя бы одна ожидающая выплата, нажмите **Confirm payouts**, чтобы [проверить и подтвердить её](/help/managing-a-program/sending-payouts/partner-payouts#как-платить-партнёрам).

**Total paid** — общая сумма всех выплат.

- **Completed payouts** — выплаты, подтверждённые ЮКассой (`payout.succeeded` webhook)
- **Processing payouts** — выплаты в обработке (обычно несколько минут для СБП/карты)

Нажмите **View invoices**, чтобы получить акты по прошлым выплатам.

В таблице выплат можно отслеживать и подтверждать ожидающие, просматривать прошедшие.

![Таблица выплат](https://s3.revroute.ru/dub-public/assets/cms/payouts-table.png)

| Столбец | Описание                                                                                       |
| ------- | ---------------------------------------------------------------------------------------------- |
| Period  | Диапазон выплаты — от даты первой комиссии партнёра до конца месяца последней                  |
| Partner | Партнёр-получатель                                                                             |
| Status  | Текущий [статус](/help/managing-a-program/sending-payouts/partner-payouts#статусы-выплат)     |
| Paid    | Дата и инициатор подтверждения                                                                 |
| Amount  | Сумма к выплате партнёру                                                                       |

## Статусы выплат

| Статус     | Описание                                                                                                                                                                                                                                                |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pending    | Выплаты, ещё не обработанные — текущие или ждущие, пока партнёр [настроит метод выплат](/help/partnering-with-programs/receiving-payouts/receiving-payouts), либо ниже [минимальной суммы](#минимальная-сумма-выплаты).                                     |
| Processing | Выплата [подтверждена](#как-платить-партнёрам) и отправлена в ЮКассу. Обычно несколько минут, при задержках банка — до нескольких часов.                                                                                                              |
| Sent       | ЮКасса приняла выплату и переводит средства на карту / СБП-получателя.                                                                                                                                                                                  |
| Completed  | Перевод подтверждён ЮКассой (`payout.succeeded` webhook). Средства зачислены партнёру.                                                                                                                                                                  |
| Failed     | Перевод отклонён — обычно из-за заблокированной/просроченной карты или несуществующего СБП-получателя. Партнёру нужно обновить метод выплат, после чего вы можете повторить.                                                                            |
| Canceled   | Выплата отменена — обычно при блокировке партнёра в программе.                                                                                                                                                                                          |

<Tip>
  Статусы обновляются автоматически из ЮКассы через
  [webhooks `payout.succeeded` и `payout.canceled`](https://yookassa.ru/developers/api#payout_object).
  Никаких ручных действий от вас не требуется.
</Tip>

## Период удержания выплат

В Revroute можно установить «период удержания выплат» — сколько комиссии будут в статусе «pending», прежде чем стать доступными для выплаты.

Это защищает от потенциальных возвратов, чарджбеков и фрода.

<Info>
  Если продажа, отслеженная через ваш биллинг (ЮКасса или кастомная
  интеграция), будет возвращена, Revroute автоматически пометит
  [соответствующую комиссию как возвращённую](/help/managing-a-program/rewards-and-commissions/partner-commissions#статусы-комиссий) — при условии что вы передавали `invoiceId` при трекинге продажи.
</Info>

Для настройки — перейдите в [группу партнёров](/help/managing-a-program/getting-started/partner-groups) → **Settings** → **Additional settings**.

![Настройки выплат](https://s3.revroute.ru/dub-public/assets/cms/group-additional-settings.png)

Доступные варианты:

- 0 дней (по умолчанию)
- 7 дней
- 14 дней
- 30 дней
- 60 дней
- 90 дней

При обновлении периода можно применить настройку сразу ко всем группам — отметьте `Apply to all groups`.

![Период удержания](https://s3.revroute.ru/dub-public/assets/cms/confirm-holding-period.png)

## Минимальная сумма выплаты

Можно задать опциональную «минимальную сумму выплаты» (например, 1 000 ₽). Партнёры с заработком ниже минимума не попадают в выплаты, пока не достигнут порога.

Нажмите кнопку справа сверху → **Payout settings**. В отличие от периода удержания, это настройка на всю программу.

![Кнопка настроек](https://s3.revroute.ru/dub-public/assets/cms/program-payout-settings.png)

![Настройки выплат](https://s3.revroute.ru/dub-public/assets/cms/payout-settings-drawer.png)

## Как платить партнёрам

Когда один или несколько партнёров превысили минимальную сумму, нажмите **Confirm payouts** в [заголовке сводки](/help/managing-a-program/sending-payouts/partner-payouts#панель-управления-выплатами).

- **Источник выплат:** аккаунт ЮКасса Payouts вашего workspace. Убедитесь, что баланс ЮКассы достаточен для всей партии — пополнить можно в [личном кабинете ЮКассы](https://yookassa.ru/my).
- **Cutoff Period:** если задан, оплатятся только комиссии до этой даты. Полезно для сверочных выплат за период (прошлый месяц/квартал).

Если всё корректно, нажмите **Confirm payout** — выплаты уйдут партнёрам.

Под капотом Revroute вызывает `POST /v3/payouts` ЮКассы по одному разу на партнёра, используя сохранённый токен карты или СБП-получатель как `payout_destination_data` и идемпотентный ключ на основе ID выплаты.

### Исключение выплат

Можно исключить конкретного партнёра из текущей партии — наведите на строку и нажмите **Exclude**.

![Исключение выплат](/images/partners-overview/exclude-payout.png)

Чтобы вернуть — наведите и нажмите **Include**.

## Комиссии ЮКассы и сроки

ЮКасса берёт комиссию за каждый перевод по вашему контракту — обычно 1–3% для карт и фиксированная плата за СБП. Точные ставки — в вашем контракте с ЮКассой.

| Метод      | Типичная комиссия (по контракту с ЮКассой) | Сроки                       |
| ---------- | ------------------------------------------ | --------------------------- |
| Банковская карта | 1–3%                                | До нескольких минут         |
| СБП        | Фикс (например, 10 ₽)                      | Мгновенно (секунды)         |

Для больших объёмов выплат СБП — самый экономичный вариант.

## Пополнение баланса для выплат

Чтобы платить партнёрам, на кошельке ЮКасса Payouts вашего workspace должен быть рублёвый баланс. Обычно пополняется банковским переводом с расчётного счёта компании; актуальные инструкции — в [руководстве ЮКассы](https://yookassa.ru/developers/payouts/scenario-extensions/work-with-balance).

Revroute проверяет баланс через `GET /v3/me` перед подтверждением партии выплат и предупредит, если средств не хватает.
