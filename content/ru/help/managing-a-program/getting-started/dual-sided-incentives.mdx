# Двусторонние стимулы

<Tip>
  Эта функция доступна только на [тарифных планах Business и
  выше](https://revroute.ru/pricing).
</Tip>

В [RevRoute Partners](https://revroute.ru/) вы можете создавать двусторонние стимулы для ваших партнерских/реферальных программ, которые предоставляют специальные скидки клиентам, зарегистрировавшимся по реферальной ссылке.

Примеры:

- Скидка 25% на первые 12 месяцев
- Пожизненная скидка 30%
- Разовая скидка 5 000 ₽

Это может стимулировать мощный рост через «сарафанное радио», поскольку партнеры с большей вероятностью будут делиться своей ссылкой, если она дает их аудитории дополнительные скидки, а с другой стороны, их пользователи с большей вероятностью будут переходить по ссылкам, если получат специальное предложение.

В этой статье мы узнаем, как настроить двусторонние стимулы с RevRoute Partners.

<Note>
  Для двусторонних стимулов вам нужна биллинговая система на вашей стороне,
  которая поддерживает купоны или промокоды. RevRoute хранит идентификатор
  купона, созданного/зарегистрированного в вашей биллинговой системе, и
  передаёт его в ваш процесс оформления заказа — ваше приложение отвечает за
  применение этого купона при оплате.
</Note>

## Вариант 1: Скидки на основе ссылок (рекомендуется)

Этот вариант привязывает скидку к самой реферальной ссылке партнера. Клиенту не нужно вводить код — ваш процесс оформления заказа автоматически применяет нужный купон в зависимости от того, какой партнер его привёл.

<Note>
Скидки на основе ссылок обеспечивают **лучшую точность атрибуции**, так как вы
получаете информацию о геолокации клиента, устройстве, данных реферера и
UTM-параметрах.

Компромисс заключается в том, что для настройки потребуется участие разработчиков.

</Note>

<Steps>
<Step title="Создайте скидку в RevRoute">
Сначала перейдите к группе партнеров, для которой вы хотите создать скидку, откройте вкладку **Скидки** и нажмите **Создать**.

![Вкладка «Скидки» группы партнёров](/images/ru/program/discounts/group-discounts.jpg)

В окне **Создать скидку** выберите тип:

- **Скидка** — процент или фиксированная скидка на оплату. Задайте значение и срок действия: **разово**, **на 1–48 месяцев** или **пожизненно**.
- **Бонус** — бонус в единицах, который начисляет ваш биллинг (например, дополнительные месяцы или кредиты). Задайте **Количество**, **Единицу** и **Описание**.

В блоке **Кому** видно, на каких партнёров группы распространится скидка. Подтвердите кнопкой **Создать скидку**.

![Окно «Создать скидку»](/images/ru/program/discounts/discount-create.jpg)

Сам купон или промокод живёт в вашей биллинговой системе: скидка RevRoute описывает условия, а применяет их ваше приложение при оформлении заказа — об этом следующий шаг.

<Warning>
Большинство биллинговых систем не поддерживают обновление купонов после
создания, поэтому если вы хотите изменить параметры скидки — придётся удалить
её в RevRoute и создать новую.

Примечание: Удаление скидки в RevRoute не удаляет соответствующий купон в
вашей биллинговой системе.

</Warning>

</Step>

<Step title="Добавьте логику купона в процесс оформления заказа">
Ключ к реализации скидок на основе ссылок — проверка права клиента на скидку через Customers API от RevRoute, а затем автоматическое применение соответствующего купона к сессии оформления заказа.

Вот как работает процесс:

1. Когда пользователь нажимает на реферальную ссылку партнера, RevRoute отслеживает его как потенциального клиента
2. Во время оформления заказа вы запрашиваете Customers API от RevRoute, используя ID пользователя
3. Если клиент имеет право на скидку, вы применяете купон к сессии оформления заказа в вашей биллинговой системе
4. Если нет, вы разрешаете ручной ввод промокодов

Пример ниже иллюстрирует логику с обобщённым клиентом биллинговой системы. Замените `billing.checkout.create(...)` на эквивалентный вызов в вашей биллинговой системе.

<CodeGroup>

```ts TypeScript expandable
import { dub } from "@/lib/dub.ts";
import { billing } from "@/lib/billing.ts"; // клиент вашей биллинговой системы

// Get customer discount eligibility from RevRoute
const customers = await dub.customers.list({
  externalId: userId, // their user ID within your app
  includeExpandedFields: true,
});

const customerDiscount = customers.length > 0 ? customers[0].discount : null;

// Create checkout session with conditional discount
const session = await billing.checkout.create({
  successUrl: "https://app.domain.com/upgraded",
  cancelUrl: "https://app.domain.com/pricing",
  lineItems: [
    {
      priceId: "price_xxx",
      quantity: 1,
    },
  ],
  mode: "subscription", // or "payment" for one-time purchases
  ...(customerDiscount
    ? {
        // Apply discount automatically if customer is eligible
        couponId:
          process.env.NODE_ENV !== "production" &&
          customerDiscount.couponTestId
            ? customerDiscount.couponTestId
            : customerDiscount.couponId,
      }
    : {
        // Allow manual promo code entry if no automatic discount
        allowPromotionCodes: true,
      }),
  customerEmail: userEmail,
  metadata: {
    userId,
    ...(customerDiscount && { dubDiscountId: customerDiscount.id }),
  },
});
```

```python Python expandable
from dub import RevRoute
from billing import client as billing  # клиент вашей биллинговой системы
import os

revroute_client = RevRoute(token=os.environ.get("REVROUTE_API_KEY"))

user_id = "user_123"  # the user's ID in your app

# Get customer discount eligibility from RevRoute
customers = revroute_client.customers.list(
    email=None,
    external_id=user_id,
    include_expanded_fields=True
)

# Prepare checkout session parameters
session_params = {
    "success_url": "https://app.domain.com/upgraded",
    "cancel_url": "https://app.domain.com/pricing",
    "line_items": [{"price": "price_xxx", "quantity": 1}],
    "mode": "subscription",  # or "payment" for one-time purchases
    "customer_email": user_email,
    "metadata": {
        "userId": user_id,
    },
}

# Apply discount if customer is eligible
if customers and hasattr(customers[0], "discount") and customers[0].discount and customers[0].discount.coupon_id:
    coupon_id = customers[0].discount.coupon_test_id if (
        os.environ.get("NODE_ENV") != "production"
    ) and hasattr(customers[0].discount, "coupon_test_id") else customers[0].discount.coupon_id

    session_params["coupon_id"] = coupon_id
    session_params["metadata"]["dubDiscountId"] = customers[0].discount.id
else:
    session_params["allow_promotion_codes"] = True

# Create the checkout session
session = billing.checkout.create(**session_params)
```

</CodeGroup>

После настройки подходящие клиенты автоматически увидят применённый промокод при оформлении заказа.

</Step>

</Steps>

## Вариант 2: Использование промокодов (без кода)

Если вы предпочитаете решение без кода, вы можете настроить скидки на основе промокодов для ваших партнеров.

<Note>
Скидки на основе промокодов гораздо проще настроить (код не требуется).

Однако вы жертвуете точностью атрибуции, так как у вас не будет данных
о геолокации клиента, устройстве, реферере и UTM-параметрах. RevRoute
попытается определить местоположение клиента на основе его платёжного адреса
в вашей биллинговой системе, но это может быть неточным.

</Note>

<Steps>
<Step title="Создайте скидку в RevRoute">
Создайте скидку для группы партнёров так же, как в [варианте 1](#вариант-1-скидки-на-основе-ссылок-рекомендуется): вкладка **Скидки** → **Создать**.

### Автоматическое создание промокодов

Включите в окне скидки переключатель **Автоматически создавать промокоды** — тогда промокоды будут автоматически созданы для всех существующих партнеров группы и для будущих партнеров при вступлении в эту группу.

</Step>

<Step title="Создайте код партнёра">
Откройте профиль партнёра, для которого вы хотите создать промокод, и нажмите **Создать код** в блоке **Промокоды** на вкладке **Ссылки**. Промокод привязывается к одной из реферальных ссылок партнёра, и у каждой ссылки может быть только один код.

Если кнопка неактивна, наведите на неё курсор — подсказка объяснит причину: у группы партнёра нет скидки или у всех его ссылок уже есть промокоды. Во втором случае сначала создайте партнёру новую ссылку.

![Блок «Промокоды»: код «ТЕСТ» привязан к единственной ссылке партнёра, поэтому кнопка «Создать код» неактивна](/images/ru/program/discounts/partner-promo-code.jpg)

Кнопка **Создать код** открывает окно **New discount code** (его интерфейс пока на английском). Выберите в списке **Referral link** ссылку, к которой привязать код, введите код в поле **Discount code** — в подсказке поля показано имя партнёра заглавными буквами — и нажмите **Create discount code**.

![Окно создания промокода: выбор реферальной ссылки и поле для кода](/images/ru/program/discounts/promo-code-create.jpg)

<Warning>
  Промокоды нельзя редактировать после создания — только удалить. Проверьте код
  и ссылку, прежде чем создавать его.
</Warning>

Созданный код появится в блоке **Промокоды** рядом со ссылкой, к которой он привязан. В панели партнёра он также увидит связанный промокод в своих партнёрских ссылках.

</Step>
</Steps>

## Отображение баннера скидки

После настройки двусторонних стимулов следующим шагом может быть отображение информации о скидке на вашей странице с ценами или главной странице.

Для этого вам нужно только установить [скрипт RevRoute Analytics](/docs/sdks/client-side/introduction) с включенным отслеживанием кликов на стороне клиента — тогда, когда кто-то перейдет на ваш сайт по действующей реферальной ссылке, скрипт автоматически получит данные о партнере и скидке.

Данные партнёра и скидки скрипт сохраняет в cookie `rr_partner_data` —
JSON-объект такого вида:

```json
{
  "clickId": "xxx",
  "partner": {
    "id": "pn_xxx",
    "name": "Иван Петров",
    "image": "https://example.com/ivan.png",
    "groupId": "grp_xxx",
    "tenantId": null
  },
  "discount": {
    "id": "disc_xxx",
    "amount": 25,
    "type": "percentage",
    "maxDuration": 3,
    "couponId": "XZuejd0Q",
    "couponTestId": "2NMXz81x"
  }
}
```

`type` — либо `percentage` (процент), либо `flat` (фиксированная сумма);
`maxDuration` — сколько месяцев действует скидка (`null` — бессрочно).

В коде страницы те же данные доступны в объекте `window.RevRouteAnalytics`.
Читать их надо внутри колбэка `ready`: к этому моменту скрипт уже получил
данные клика.

```html
<script>
  revRouteAnalytics("ready", function () {
    const { partner, discount } = window.RevRouteAnalytics;
    if (!partner || !discount) return;

    const banner = document.createElement("div");
    banner.innerHTML = `
      <img src="${partner.image}" alt="${decodeURIComponent(partner.name)}" />
      <p>
        ${decodeURIComponent(partner.name)} рекомендует вам Acme
        и дарит скидку ${discount.amount}${discount.type === "percentage" ? "%" : " ₽"}
      </p>
    `;
    document.body.appendChild(banner);
  });
</script>
```

<Warning>
  `partner.name` и `partner.image` хранятся в cookie в URL-кодировке — перед
  выводом их нужно пропустить через `decodeURIComponent`.
</Warning>
