# Настройка реферальных ссылок для групп партнеров

<Tip>
  Эта функция доступна только на [тарифных планах Business и
  выше](https://revroute.ru/pricing).
</Tip>

## Где найти настройки реферальных ссылок

Каждая [группа партнеров](/help/managing-a-program/getting-started/partner-groups) имеет собственные настройки реферальных ссылок. Чтобы найти их, откройте группу и перейдите на вкладку **Ссылки**.

## Реферальные ссылки по умолчанию

Ссылки по умолчанию автоматически создаются для каждого партнера в группе — и для тех, кто уже в ней, и для тех, кто присоединится позже. Обычно первая такая ссылка появляется при настройке программы; если блок **Ссылки по умолчанию** пуст, как на скриншоте выше, партнерам группы ссылки автоматически не выдаются.

Чтобы добавить ссылку по умолчанию, нажмите **Создать ссылку** в блоке **Ссылки по умолчанию**.

<Info>
  При создании ссылки по умолчанию вас попросят указать **Целевой URL**.
  Это страница, на которую попадают пользователи после нажатия на реферальную
  ссылку. Обычно это ваша главная страница или специальная целевая страница
  программы.
</Info>

**Поведение ссылок по умолчанию**

- **При создании ссылки по умолчанию** новая ссылка генерируется для каждого партнера в этой группе. Это относится как к текущим, так и к будущим партнерам в этой группе.
- **При обновлении URL назначения ссылки по умолчанию** обновляются все соответствующие партнерские ссылки в этой группе с указанным URL назначения.
- **При удалении ссылки по умолчанию** ссылка остается у существующих партнеров в этой группе для сохранения исторической статистики и комиссий.

## Дополнительные партнерские ссылки

Вы также можете позволить вашим партнерам создавать собственные ссылки помимо стандартных. Для этого включите переключатель **Включить дополнительные партнёрские ссылки** и нажмите **Сохранить изменения**. После включения доступны настройки:

- **Лимит ссылок** — сколько дополнительных ссылок может создать партнер;
- **Форматы ссылок** — домены или URL, на которые партнеры могут создавать ссылки. Пока ни одного формата нет, партнеры не смогут создавать дополнительные ссылки.

Чтобы добавить формат, нажмите **Добавить формат** и выберите тип: **Любой URL** — ссылки на любые страницы указанного домена (рекомендуется) или **Один URL** — ссылки только на конкретную страницу.

![Окно «Добавить формат ссылки»](/images/ru/program/groups/group-link-format.jpg)

<Warning>
  Убедитесь, что на добавляемом домене настроено отслеживание конверсий,
  иначе ваши ссылки не будут отслеживаться корректно. [Подробнее.](/docs/quickstart/server)
</Warning>

## Настройки ссылок

В блоке **Настройки ссылок** той же вкладки определите структуру ссылок и UTM-параметры для всех партнеров в группе.

### Структура ссылок

RevRoute поддерживает два формата реферальных ссылок — в интерфейсе они называются **Short Link** и **Query Parameter**. Выберите в зависимости от того, как вы хотите, чтобы ссылки выглядели и где они будут использоваться. Оба формата работают одинаково для атрибуции.

<Info>
  Вы можете использовать любые типы реферальных ссылок взаимозаменяемо — опция
  выше определяет, какой формат отображается в панели партнера.
</Info>

**Вариант 1: Короткие ссылки (Short Link)**

**Формат:** `getacme.link/{partnerName}`

Чистая, брендированная короткая ссылка, которую легко запомнить и удобно использовать в публикациях в социальных сетях, биографиях или сообщениях.

<Tip>
  Мы рекомендуем использовать короткие ссылки по нескольким причинам:

  1. Некоторые браузеры блокируют [отслеживание кликов на стороне клиента](/docs/sdks/client-side/features/click-tracking), что нарушает атрибуцию — с `getacme.link/john` клик будет отслеживаться и на стороне сервера, что повышает точность атрибуции
  2. Некоторые браузеры удаляют параметры запроса, что также нарушает атрибуцию
  3. Это выглядит аккуратнее
</Tip>

**Вариант 2: Параметр запроса (Query Parameter)**

**Формат:** `acme.com?via={partnerName}`

Добавляет имя партнера в качестве строки запроса к вашему URL назначения. Идеально для пользователей, которые [мигрируют с Rewardful](/help/managing-a-program/migration-guides/migrating-from-rewardful) и хотят сохранить обратную совместимость с существующими партнерскими ссылками.

### UTM-параметры

Установите [UTM-параметры](/help/managing-your-links/links/utm-builder) по умолчанию для всех ссылок в этой группе: **Источник**, **Канал**, **Кампания**, **Ключевое слово**, **Содержимое** и **Реферал**. Это дает вам аналитику по конкретным группам.

При обновлении [шаблона UTM](/help/managing-your-links/links/how-to-create-utm-templates) группы все партнерские ссылки в
группе обновляются и перезаписываются новыми UTM-тегами.

## Как изменение группы партнеров влияет на реферальные ссылки

Как упоминалось ранее, настройки ссылок партнера привязаны к [группе партнеров](/help/managing-a-program/getting-started/partner-groups), в которой он состоит. При обновлении группы партнера или удалении групп его партнерские ссылки также будут обновлены.

### Перемещение партнеров в группу

При перемещении партнера в новую группу его ссылки автоматически обновляются в соответствии с настройками по умолчанию и UTM-параметрами новой группы.

<Info>
  **Зачем перемещать партнеров?**

  - Для перевода их из начальной группы в группу с более высоким уровнем вознаграждения
  - Для тестирования новых вознаграждений в тестовой группе
  - Для упорядочивания структуры и общей реорганизации
</Info>

### Удаление групп

При удалении группы все партнеры в этой группе перемещаются в группу по умолчанию. Их ссылки обновляются в соответствии с настройками группы по умолчанию.

<Info>
  **Зачем удалять группу?**

  - Кампания завершена
  - Вы создали дублирующую группу по ошибке
  - Бета-тестовая группа больше не нужна
</Info>
