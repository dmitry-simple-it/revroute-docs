# RevRoute documentation and help center

Everything RevRoute publishes lives here. The two sections differ by audience:
the documentation is written for developers, the help center for whoever works
in the dashboard.

## Starting from scratch

If you are connecting RevRoute for the first time, follow the route in
[Getting started](/docs/getting-started): domain → tracking script → `lead` and
`sale` events → webhooks.

If you are launching a partner program and don't write code,
[setting up your program](/help/managing-a-program/getting-started/setting-up-your-program)
in the help center is the place to begin.
