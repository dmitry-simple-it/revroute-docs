# Как импортировать ссылки из CSV-файла

Вы также можете импортировать существующие ссылки в RevRoute с помощью функции импорта CSV. Это полезно, если у вас большой список ссылок для импорта или если вы хотите [импортировать ссылки из другого сервиса](/help/managing-your-links/migration-guides/migrating-from-bitly), для которого у нас нет импортёра в один клик.

Чтобы импортировать ссылки, выполните следующие шаги:

<Steps>

<Step title="Подготовьте CSV-файл">

Перед импортом CSV-файла убедитесь, что он имеет правильный формат. Ваш CSV-файл должен содержать следующие данные:

| Поле RevRoute   | Обязательно | Описание                                  | Пример                              |
| --------------- | ----------- | ----------------------------------------- | ----------------------------------- |
| URL назначения  | **Да**      | Адрес, на который ведёт ссылка.           | `https://cloudflow-demo.ru/pricing` |
| Короткая ссылка | **Да**      | Короткая ссылка — домен и ключ.           | `yourdomain.ru/abc123`              |
| Заголовок       | Нет         | Заголовок ссылки.                         | `Тарифы CloudFlow`                  |
| Описание        | Нет         | Описание ссылки.                          | `Страница с ценами`                 |
| Теги            | Нет         | Теги ссылки — список тегов через запятую. | `тарифы, сайт`                      |
| Дата создания   | Нет         | Дата создания ссылки.                     | `2026-08-01`                        |

Названия столбцов в файле могут быть любыми — на следующем шаге вы сопоставите их с полями RevRoute. Главное, чтобы в файле были обязательные столбцы.

</Step>

<Step title="Загрузите CSV-файл">

Если вы ещё этого не сделали, [создайте рабочее пространство в RevRoute](/help/managing-your-workspace/what-is-a-workspace).

<Info>
  **Совет**: После создания рабочего пространства мы рекомендуем **_не
  [настраивать домен](/help/managing-your-links/custom-domains/how-to-add-custom-domain)_** до тех пор, пока
  вы не перенесёте все ссылки. Это предотвратит возможные перебои в работе
  ваших ссылок.
</Info>

Затем на [странице ссылок](https://app.revroute.ru/links) нажмите кнопку **⋮** справа от поиска и выберите **Импорт из CSV**.

![Меню ⋮ на странице ссылок: «Импорт из CSV» и «Экспорт в CSV»](/images/ru/links/migration/links-import-menu.jpg)

Откроется окно **Импорт ссылок из CSV-файла**.

![Окно «Импорт ссылок из CSV-файла» с полем загрузки](/images/ru/links/migration/import-csv-modal.jpg)

Нажмите на поле загрузки или перетащите в него CSV-файл — окно сразу перейдёт к следующему шагу.

</Step>

<Step title="Проверьте автоматическое сопоставление столбцов">

После загрузки RevRoute с помощью ИИ сопоставит столбцы файла с [полями ссылки в RevRoute](/docs/concepts/links/introduction): слева — столбец CSV, справа — поле данных RevRoute. Обязательные поля отмечены звёздочкой.

![Сопоставление столбцов CSV с полями RevRoute перед импортом](/images/ru/links/migration/import-csv-mapping.jpg)

Проверьте сопоставления, при необходимости поправьте их и нажмите **Подтвердить импорт**. Через несколько секунд ссылки появятся в RevRoute.

Чтобы загрузить другой файл, нажмите **Выбрать другой файл**.

</Step>

<Step title="Проверьте результаты импорта">

Когда все ссылки будут импортированы, RevRoute пришлёт письмо о завершении импорта. Если с частью ссылок возникли проблемы, придёт отдельное письмо с подробностями об ошибках.

</Step>

<Step title="Настройте домен">

После импорта всех ссылок вы можете [настроить домен](/help/managing-your-links/custom-domains/how-to-add-custom-domain#шаг-2-настройка-домена), указав правильные DNS-записи. После этого вы можете начать использовать ваши ссылки!

</Step>

</Steps>
