Сначала включите отслеживание конверсий для ссылок: без него клик не связывается
с последующими событиями лида и продажи.

<Tip>
  Для ссылок партнёрской программы шаг можно пропустить — RevRoute включает
  отслеживание конверсий у них автоматически.
</Tip>

**Для всего воркспейса.** Откройте
[**Настройки → Аналитика**](https://app.revroute.ru/settings/analytics) и включите
переключатель **Отслеживание конверсий** в шапке страницы — он управляет
настройкой на уровне воркспейса. Отслеживание включится у всех ссылок, созданных
после этого.

**Для отдельной ссылки.** Откройте
[конструктор ссылки](/help/managing-your-links/additional-guides/link-builder) и
включите переключатель **Отслеживание конверсий** — внутри конструктора он же
дёргается горячей клавишей `C`.

**Через API.** Передайте `trackConversion: true` при создании или обновлении
ссылки (по умолчанию — `false`):

```bash
curl -X POST "https://api.revroute.ru/links" \
  -H "Authorization: Bearer dub_xxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "trackConversion": true
  }'
```
