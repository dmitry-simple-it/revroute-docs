# Как использовать теги в RevRoute

Теги — отличный способ организации ссылок в RevRoute. Используйте теги для группировки ссылок и быстрого поиска.

![Список ссылок с тегами в RevRoute](/images/ru/links/links-list-tags.jpg)

## Что такое тег?

Тег — это метка, которую можно присвоить ссылке. Теги имеют цветовую кодировку и создаются в несколько кликов.

С помощью тегов вы можете:

1. Организовать ссылки по кампаниям, клиентам или любым другим категориям.
2. Фильтровать ссылки по тегам и получать ссылку на отфильтрованные результаты.
3. [Фильтровать аналитику по тегам](/help/managing-your-links/analytics/filtering-analytics/filter-analytics-by-tags) для отслеживания эффективности кампаний.

## Как создать тег

Перейдите на [страницу настроек тегов](https://app.revroute.ru/settings/library/tags) в вашем рабочем пространстве RevRoute.

![Страница настроек тегов](/images/ru/links/tags-settings-page.jpg)

Нажмите **Создать тег** (или клавишу `C`) для открытия модального окна создания тега, где можно задать имя и выбрать цвет:

![Модальное окно создания тега](/images/ru/links/create-tag-modal.jpg)

Также можно создавать теги прямо в [конструкторе ссылок RevRoute](/help/managing-your-links/additional-guides/link-builder). После [создания ссылки](/help/managing-your-links/links/how-to-create-link) нажмите на поле ввода тега и введите название.

![Выбор тега в конструкторе ссылок](/images/ru/links/tag-select-dropdown.jpg)

Если тег уже существует, выберите его из выпадающего списка. Иначе нажмите `Enter` для создания нового.

После создания тега нажмите «Создать ссылку» для присвоения тега ссылке.

## Как отредактировать или удалить тег

Теги редактируются на [странице настроек тегов](https://app.revroute.ru/settings/library/tags).

Нажмите кнопку `⋮` для открытия меню с опциями:

- Редактировать
- Скопировать ID тега (для [программного использования](/help/managing-your-links/links/how-to-use-tags#программное-управление-тегами))
- Удалить

![Меню тега](/images/ru/links/tag-row-menu.jpg)

Горячие клавиши для управления тегами:

| Сочетание | Действие              |
| --------- | --------------------- |
| `E`       | Редактировать тег     |
| `I`       | Скопировать ID тега   |
| `X`       | Удалить тег           |

В модальном окне редактирования можно:

- Переименовать тег
- Изменить цвет тега

![Модальное окно редактирования](/images/ru/links/edit-tag-modal.jpg)

## Можно ли присвоить несколько тегов ссылке?

Да. В разделе тегов для ссылки можно выбрать несколько тегов.

![Несколько тегов для ссылки](/images/ru/links/multiple-tags-dropdown.jpg)

Теги отображаются в списке ссылок, и вы можете фильтровать ссылки по ним.

## Сколько тегов можно создать?

Количество зависит от тарифа:

- **Free**: До 5 тегов
- [**Pro**](https://revroute.ru/pricing): До 25 тегов
- [**Business**](https://revroute.ru/pricing): Без ограничений
- [**Enterprise**](https://revroute.ru/): Без ограничений

Подробнее на [странице тарифов](https://revroute.ru/pricing).

## Программное управление тегами

Создавать теги и получать их список можно через [RevRoute API](/docs/api-reference/introduction); как выпустить токен доступа — в разделе [аутентификации](/docs/api-reference/authentication).
