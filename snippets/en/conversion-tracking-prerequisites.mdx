## The server-side client

The examples below use the TypeScript SDK from the `dub` npm package. Always
pass the RevRoute API `serverURL` to the client — without it the SDK will not
talk to our API.

```bash
npm install dub
```

```ts lib/revroute.ts
import { Dub } from "dub";

export const revroute = new Dub({
  token: process.env.REVROUTE_API_KEY, // secret rr_* key from your workspace settings
  serverURL: "https://api.revroute.ru", // required: the RevRoute API address
});
```

<Warning>
  Keep the secret key (`rr_*`) in environment variables and never expose it to
  the browser. Create one under [API keys](https://app.revroute.ru/settings/tokens).
</Warning>

<Tip>
  The SDK is optional: `/track/lead` and `/track/sale` are plain HTTPS endpoints
  you can call from any language.
</Tip>
