# Как установить срок действия для ссылок RevRoute?

<Tip>
  Эта функция доступна только на [тарифах Pro и
  выше](https://revroute.ru/pricing).
</Tip>

В RevRoute вы можете установить срок действия для ссылок, нажав кнопку **Срок действия** в конструкторе ссылок. Откроется модальное окно **Срок действия**.

Быстрый доступ — сочетание клавиш `E` в конструкторе ссылок.

Заполните следующие поля:

1. **Дата и время**: Дата и время истечения срока действия ссылки.
2. **URL после истечения**: URL, на который пользователь будет перенаправлен после истечения срока.

Нажмите **Добавить срок действия** для сохранения.

Можно использовать естественный язык для ввода даты и времени. Например, «in 2 hours» или «tomorrow at 5pm» — RevRoute автоматически преобразует ввод в правильный формат.

Также можно выбрать дату и время вручную через выпадающий календарь.

Если установлен срок действия, после его истечения пользователи увидят страницу «Срок действия истёк».

![Страница истёкшей ссылки](/images/ru/links/expired-link-placeholder.jpg)

<Warning>
  Примечание: клики по ссылке после истечения срока ***не*** будут
  отслеживаться.
</Warning>

## Пользовательский URL для истёкших ссылок

Вы можете задать собственный URL перенаправления для истёкших ссылок. Это полезно, если хотите направлять пользователей на конкретную страницу.

Введите URL в поле **URL после истечения** в модальном окне **Срок действия**.

![URL для истёкшей ссылки](/images/ru/links/link-expiration-url.jpg)

## URL по умолчанию для всех ссылок домена

Также можно задать URL по умолчанию для истёкших ссылок на всём домене. Это полезно для перенаправления пользователей при истечении _любой ссылки на домене_.

Как настроить:

1. Перейдите на [страницу настроек доменов](https://app.revroute.ru/settings/domains) в дашборде RevRoute.
2. Нажмите кнопку `⋮` у нужного домена — откроется выпадающее меню.

![Меню домена](/images/ru/links/domain-row-menu.jpg)

3. Выберите **Редактировать домен** — откроется модальное окно **Обновить домен**.
4. Включите настройку **URL для истёкших ссылок** (доступна на тарифе Pro и выше) и введите URL перенаправления.

![Настройки домена с URL для истёкших ссылок](/images/ru/links/domain-update-modal.jpg)

5. Нажмите **Сохранить изменения** для сохранения.
