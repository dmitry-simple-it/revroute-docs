# API: ошибки

Ошибки RevRoute API возвращаются в едином формате:

```json
{
  "error": {
    "code": "unprocessable_entity",
    "message": "Invalid input",
    "doc_url": "https://revroute.ru/docs/api-reference/errors#unprocessable-entity"
  }
}
```

Поле `doc_url` ведёт в раздел этой страницы о коде ошибки: в адресе раздела подчёркивания заменены дефисами (`unprocessable_entity` → `#unprocessable-entity`).

## `unprocessable_entity` (422)

Запрос синтаксически корректен, но не проходит валидацию (например, неверный тип поля).

Частый пример:

- `testVariants` ожидается **массив**, а пришёл **объект**

Проверьте тело запроса и приведите его к ожидаемой схеме.

<span id="unauthorized" />

## `unauthorized` (401)

Нет токена или токен недействителен.

<span id="forbidden" />

## `forbidden` (403)

Токен валиден, но не хватает прав доступа.

<span id="not-found" />

## `not_found` (404)

Ресурс не найден или вам недоступен.

<span id="internal-server-error" />

## `internal_server_error` (500)

Внутренняя ошибка на стороне RevRoute. Повторите запрос позже, увеличивая паузу между попытками, — см. [что делать при ошибках 5xx](/docs/troubleshooting/api-errors#server-errors). Если ошибка повторяется, [напишите в поддержку](https://revroute.ru/contact/support): укажите метод, адрес запроса и время.
