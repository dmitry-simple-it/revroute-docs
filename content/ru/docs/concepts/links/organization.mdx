При программном создании ссылок с помощью Revroute вам может понадобиться способ связать их с пользователем или другими идентификаторами в вашей системе.

Существует несколько способов сделать это в зависимости от структуры ваших данных:

| Способ                                                        | Связь         | Что это                                                  | Когда применять                                                            |
| ------------------------------------------------------------- | ------------- | -------------------------------------------------------- | -------------------------------------------------------------------------- |
| [External ID](#внешний-идентификатор-externalid)              | один к одному | Уникальный идентификатор ссылки в вашей системе          | Связать реферальную ссылку с конкретным пользователем                      |
| [Tenant ID](#идентификатор-арендатора-tenantid)               | один ко многим | Идентификатор арендатора, создавшего ссылку              | Сгруппировать все ссылки одного пользователя или команды                   |
| [Теги](#теги)                                                  | многие ко многим | Группировка ссылок по меткам                          | Разложить ссылки по кампаниям, клиентам и другим срезам для отчётов        |
| [Папки](#папки)                                                | один ко многим | Идентификатор папки, в которой лежит ссылка              | Выстроить иерархию папок и наводить порядок в большом количестве ссылок    |

## Внешний идентификатор externalId

Иногда ссылку нужно опознавать по идентификатору из вашей системы. Например, связать реферальную ссылку с пользователем, не храня при этом идентификатор ссылки Revroute в своей базе.

Для этого и нужно поле `externalId`. Это уникальный идентификатор на вашей стороне, который сопоставляется с конкретной ссылкой в системе Revroute.

Revroute позволяет создать ссылку с `externalId`, а затем получать её по тому же идентификатору.

<Note>
  Значение `externalId` должно быть уникальным в пределах рабочего пространства.
  Попытка создать вторую ссылку с уже занятым `externalId` вернёт ошибку
  конфликта `409` — см. [«API: ошибки»](/docs/api-reference/errors).
</Note>

### Создание ссылки с externalId

Пример создания ссылки с полем `externalId`:

<CodeGroup>

```javascript Node.js
import { Revroute } from "dub";

export const dub = new Revroute({
  token: process.env.DUB_API_KEY,
});

const link = await dub.links.create({
  url: "https://google.com",
  externalId: "12345",
});
```

```go Go
package main

import(
  "context"
  dubgo "github.com/dubinc/dub-go"
  "github.com/dubinc/dub-go/models/operations"
  "log"
  "os"
)

func main() {
  ctx := context.Background()

  s := dubgo.New(
    dubgo.WithSecurity(os.Getenv("DUB_API_KEY")),
  )

  res, err := s.Links.Create(ctx, &operations.CreateLinkRequestBody{
    URL: "https://google.com",
    ExternalId: "12345",
  })

  if err != nil {
    log.Fatal(err)
  }

  if res != nil {
    // handle response
  }
}
```

```python Python
import os
import dub
from dub.models import operations

d = dub.Revroute(
  token=os.environ['DUB_API_KEY'],
)

res = d.links.create(request={
  "url": "https://google.com",
  "external_id": "12345",
})
```

```ruby Ruby
require 'dub'

s = ::OpenApiSDK::Revroute.new
s.config_security(
  ::OpenApiSDK::Shared::Security.new(
    token: "DUB_API_KEY",
  )
)

req = ::OpenApiSDK::Operations::CreateLinkRequestBody.new(
  url: "https://google.com",
  external_id: "12345",
)
```

```php PHP
declare(strict_types=1);

require 'vendor/autoload.php';

use Revroute;
use Revroute\Models\Operations;

$sdk = Revroute\Revroute::builder()->setSecurity('DUB_API_KEY')->build();

$request = new Operations\CreateLinkRequestBody(
  url: 'https://google.com',
  externalId: '12345',
);

$response = $sdk->links->create(
  request: $request
);
```

```bash cURL
curl --request POST \
  --url https://api.revroute.ru/links \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "url": "https://google.com",
    "external_id": "12345"
  }'
```

</CodeGroup>

### Обновление ссылки по externalId

Ссылку можно обновлять не только по `linkId`, но и по `externalId`.

<Note>
  Не забудьте префикс `ext_` перед значением `externalId`. Например, если
  `externalId` равен `12345`, передавать нужно `ext_12345`.
</Note>

<CodeGroup>

```javascript Node.js
import { Revroute } from "dub";

export const dub = new Revroute({
  token: process.env.DUB_API_KEY,
});

const link = await dub.links.update("ext_12345", {
  url: "https://www.google.uk", // new URL
});
```

```go Go
package main

import(
  "context"
  dubgo "github.com/dubinc/dub-go"
  "github.com/dubinc/dub-go/models/operations"
  "log"
  "os"
)

func main() {
  ctx := context.Background()

  s := dubgo.New(
    dubgo.WithSecurity(os.Getenv("DUB_API_KEY")),
  )

  res, err := s.Links.Update(ctx, "ext_12345", &operations.UpdateLinkRequestBody{
    URL: "https://www.google.uk", // new URL
  })

  if err != nil {
    log.Fatal(err)
  }

  if res != nil {
    // handle response
  }
}
```

```python Python
import os
import dub
from dub.models import operations

d = dub.Revroute(
  token=os.environ['DUB_API_KEY'],
)

res = dub.links.update(link_id="ext_12345", request_body={
  "url": "https://www.google.uk", // new URL
})
```

```ruby Ruby
require 'dub'

s = ::OpenApiSDK::Revroute.new
s.config_security(
  ::OpenApiSDK::Shared::Security.new(
    token: "DUB_API_KEY",
  )
)

res = s.links.update(link_id="ext_12345", request_body={
  "url": "https://www.google.uk", // new URL
})
```

```php PHP
declare(strict_types=1);

require 'vendor/autoload.php';

use Revroute;
use Revroute\Models\Operations;

$sdk = Revroute\Revroute::builder()->setSecurity('DUB_API_KEY')->build();

$requestBody = new Operations\UpdateLinkRequestBody(
  url: 'https://www.google.uk', // new URL
);

$response = $sdk->links->update(
  linkId: 'ext_12345',
  requestBody: $requestBody
);
```

```bash cURL
curl --request PATCH \
  --url https://api.revroute.ru/links/ext_12345 \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{"url": "https://www.google.uk"}'
```

</CodeGroup>

## Идентификатор арендатора tenantId

Идентификатор арендатора, создавшего ссылку в вашей системе. Если он задан, по нему можно получить все ссылки этого арендатора. Приём полезен, когда пользователи создают ссылки сами, а вам нужно группировать их по владельцу.

## Теги

Теги — самый гибкий способ навести порядок в ссылках Revroute.

С тегами вы можете:

- раскладывать ссылки по кампаниям, клиентам и любым другим категориям;
- [фильтровать ссылки по тегам](#получение-ссылок-по-тегам) и делиться ссылкой на отфильтрованную выборку;
- [фильтровать аналитику по тегам](#аналитика-по-тегам), чтобы оценивать эффективность кампаний.

## Папки

Папки — иерархический способ организации ссылок в Revroute.

С папками вы можете:

- раскладывать ссылки по каталогам;
- [фильтровать ссылки по папке](#получение-ссылок-по-папке) и делиться ссылкой на отфильтрованную выборку;
- [фильтровать аналитику по папке](#аналитика-по-папке), чтобы оценивать эффективность кампаний.
