# Как экспортировать данные аналитики ссылок из RevRoute

Аналитика может быть мощным инструментом для понимания того, как ваша аудитория взаимодействует с контентом, и для принятия решений на основе данных.

Для RevRoute всегда было приоритетом предоставлять [аналитику мирового класса](/help/managing-your-links/analytics/analytics-overview) для всех.

Чтобы получить больше от вашей аналитики, вы можете экспортировать данные аналитики в CSV-файл. Это может быть полезно, если вы хотите проанализировать данные в инструменте бизнес-аналитики (BI), поделиться ими с командой или импортировать их в электронную таблицу.

## Экспорт данных аналитики ссылок

Чтобы экспортировать данные аналитики ссылок, выполните следующие шаги:

<Steps>

<Step title="Перейдите на страницу аналитики">

Перейдите в [панель управления RevRoute](https://app.revroute.ru), войдите в систему и выберите проект, из которого хотите экспортировать данные.

Откройте пункт **«Аналитика»** в разделе **«Статистика»** левого сайдбара.

</Step>

<Step title="Скачайте данные">

Нажмите на кнопку `⋮` в правом верхнем углу страницы аналитики, чтобы открыть выпадающее меню дополнительных параметров.

Выберите пункт **«Скачать CSV»**.

![Меню «⋮» на странице аналитики с пунктом «Скачать CSV»](/images/ru/links/analytics-export.jpg)

Через несколько секунд на ваш компьютер будет загружен архив с CSV-файлами по каждому разрезу аналитики, который вы знаете по панели управления.

</Step>

</Steps>
