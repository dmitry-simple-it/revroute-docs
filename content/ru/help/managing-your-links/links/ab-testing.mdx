# Как проводить A/B-тесты с RevRoute Links?

<Info>
  A/B-тестирование доступно только на тарифных планах Business и выше. [Посмотреть все
  тарифные планы](https://revroute.ru/pricing).
</Info>

## Что такое A/B-тестирование?

A/B-тестирование — это метод сравнения двух или более вариантов целевого URL для определения, какой из них работает лучше. Он работает путем случайного перенаправления пользователей, которые нажимают на одну и ту же короткую ссылку, на разные целевые URL, а затем измеряет, какой вариант показывает лучшие результаты на основе метрик.

## Где найти A/B-тестирование?

Когда конструктор ссылок открыт, вы найдете кнопку **А/В тест** в нижнем ряду действий. Нажмите, чтобы открыть модальное окно «А/В-тестирование».

![Кнопка «А/В тест» в конструкторе ссылок](/images/ru/links/link-builder.jpg)

## Конструктор A/B-тестов

С открытым конструктором вы можете добавлять дополнительные целевые URL, устанавливать процент трафика и дату завершения. Для создания теста необходимо минимум 2 URL.

![Модальное окно «А/В-тестирование»](/images/ru/links/ab-test-dialog.jpg)

### URL для тестирования

Вы можете ввести максимум 4 дополнительных тестовых URL, на которые хотите направлять ваш трафик. Для добавления нажмите кнопку **Добавить URL**.

![URL для тестирования](/images/ru/links/ab-test-urls.jpg)

Если вам нужно удалить добавленные URL, нажмите значок **`X`** справа от каждого поля ввода.

### Распределение трафика

По умолчанию трафик распределяется равномерно между всеми URL, но это можно изменить в зависимости от ваших предпочтений.

Нажмите и перетащите разделители между каждой группой для настройки трафика на каждый целевой URL. Минимальный процент трафика, который можно установить — 10%.

### Дата завершения

По умолчанию A/B-тесты настроены на 2 недели, так как этого достаточно для сбора данных о производительности и принятия решения.

Вы можете запустить тест на более короткий период, но это не рекомендуется, поскольку в большинстве случаев вы не соберете достаточно данных для принятия решения. Максимальная продолжительность теста — 6 недель.

## Активные A/B-тесты

Пока A/B-тест активен, на каждой ссылке отображается значок колбы. Вы можете увидеть его при просмотре всех ваших ссылок.

![Значок колбы у ссылки с активным А/В-тестом](/images/ru/links/ab-test-flask-icon.jpg)

Вы можете нажать на этот значок, чтобы развернуть текущий вид ссылки и увидеть все целевые URL, которые вы ввели для тестирования. Здесь будет показан установленный процент трафика и показатели кликов, лидов и продаж.

![Развернутый просмотр ссылки с А/В-тестом](/images/ru/links/ab-test-link-expanded.jpg)

## Завершение A/B-тестов

Есть два способа завершения A/B-тестов. Они могут быть завершены вручную досрочно или по наступлении запланированной даты завершения.

<Steps>
<Step title="Наступила дата завершения">
По умолчанию ваш A/B-тест завершается, когда наступает запланированная дата. Вот как выбирается новый целевой URL:
1. Выбирается ссылка с наибольшим количеством конверсий
2. При равном количестве конверсий выбирается ссылка с наибольшим коэффициентом конверсии (конверсии / клики)
3. Если все ещё равны, выбирается ссылка с наибольшим количеством кликов

Или если конверсии не записываются и не отслеживаются:

1. Выбирается ссылка с наибольшим количеством лидов
2. При равном количестве лидов выбирается ссылка с наибольшим коэффициентом лидов (лиды / клики)
3. Если все ещё равны, выбирается ссылка с наибольшим количеством кликов

</Step>
<Step title="Завершение теста вручную">
Чтобы завершить тест до запланированной даты, откройте настройки A/B-теста и нажмите **Завершить А/В-тест** в левом нижнем углу модального окна.

![Кнопка «Завершить А/В-тест» в модальном окне](/images/ru/links/ab-test-end-button.jpg)

Здесь вы выберете новый целевой URL для вашей короткой ссылки.

![Диалог «Завершить А/В-тест»: выбор целевого URL](/images/ru/links/ab-test-end-select-url.jpg)

После нажатия **Завершить тест** убедитесь, что вы сохранили изменения ссылки на следующем экране для подтверждения изменений.

</Step>
</Steps>
