# RSS → Дзен: подключение и редакционный процесс

Актуальное известное состояние на 2026-10-20: на снимке настроек, присланном пользователем, домен `revroute.ru` подтверждён, а RSS `https://revroute.ru/feed/zen.xml` отклонён. Сообщение Дзена: «Содержимое RSS ленты не соответствует требованиям Дзена к контенту. Исправьте содержимое и добавьте RSS на проверку снова». Конкретный нарушенный пункт не указан. Повторная подача, одобрение, автоматический импорт и вёрстка в самом Дзене не подтверждены.

## История первой подачи — проверка 2026-10-15

- Статус штатного API Студии после подключения: `domain.status: "ok"`, `rss.url: "https://revroute.ru/feed/zen.xml"`, `rss.isValidating: true`, `rss.errors: []`. Это принятие заявки, а не завершение проверки.
- В Студии указано, что обработка обычно занимает несколько дней.
- Публичный RSS отвечает HTTP 200 с `application/rss+xml; charset=utf-8`, XML разбирается без ошибок. В ленте одна статья, стабильный GUID `revroute:blog:shorten-link-no-signup`, категории `native-draft` и `format-article`.
- Тело пилота: 4 подзаголовка, 17 абзацев, 3 изображения и 3 подписи. Все изображения доступны без авторизации с HTTP 200, размеры файлов совпадают с исходниками. `robots.txt` разрешает RSS, страницы и изображения. 18 тестов экспортёра прошли.
- В Дзене найден один старый черновик «Как сократить ссылку онлайн без регистрации — 30 секунд и готово», сохранённый 19 мая. Его заголовок и текст отличаются от пилота; он не доказывает текущий импорт. Опубликованных и ожидающих публикации материалов нет.
- По датам на публичной странице блога за последний месяц опубликован только один материал — от 2026-10-04. Всего в блоге 24 материала; остальные не включены в RSS.
- В официальной справке первого подключения указаны минимум 10 материалов в RSS и минимум 3 публикации на сайте за последний месяц. На 15 октября этим условиям не соответствовало количество материалов; отказа от модерации на тот момент ещё не было.

На 15 октября для соответствия этим условиям недоставало 9 согласованных материалов в RSS и 2 фактически новых публикаций за месяц. Это исторический срез первой подачи, а не текущий состав production-ленты. Старые даты и GUID не подменяются. После подтверждённого одобрения повторной заявки нужно найти именно пилот по заголовку и исходной ссылке, проверить в редакторе/превью Дзена текст, изображения, подписи, ссылки и мобильное отображение.

## Что реализовано

- `GET /feed/zen.xml`: RSS 2.0, UTF-8, полный текст в `content:encoded`, стабильный GUID, реальная обложка в `enclosure`.
- В ленту входят только записи из `content/blog.ts` с `dzen.enabled === true`. Первая согласованная статья — `/blog/shorten-link-no-signup`, дата публикации `2026-10-04`, экспорт в режиме `draft`.
- Дата вычисляется из `dzen.publishedAt` либо исходной `date`; будущие публикации не выдаются до наступления времени. Повторный запрос не меняет GUID или дату.
- `mode: 'draft'` (и отсутствие mode) добавляет `native-draft`; `mode: 'publish'` убирает директиву черновика. Реальное выполнение директивы должен подтвердить пилот в Дзене.
- Некорректная включённая статья вызывает HTTP 503. Ошибка не превращается в неполную статью.
- Локальный импорт Markdown и превью не добавляют материал в массив `posts` и не включают доставку.

## Разметка

| Исходник | Выдача для Дзена |
| --- | --- |
| Абзац / rich-p | p с экранированным текстом |
| Подзаголовки | h2, h3 |
| Выделение / курсив | b, i |
| Ссылка | a href с абсолютным HTTP(S)-адресом |
| Списки | ul/ol, li |
| Картинка с подписью | figure, img, figcaption |
| Цитата | blockquote, p |
| CTA | Абзац текста и обычная ссылка |
| Таблица | Список строк с подписями каждого столбца; все значения сохранены |
| Stats | Список значений с названиями |
| React mock | Ошибка: сначала заменить явно подготовленным изображением |
| FAQ / источники | Подзаголовки, абзацы и ссылки; без details/summary |

CSS, JavaScript, iframe, таблицы и кнопки не экспортируются. URL из примеров в тексте не переписываются: в статье про UTM нельзя удалять смысловые параметры. Обложка в enclosure не добавляется искусственно в начало тела. Первое изображение статьи может влиять на карточку — проверить фактический результат.

Для изображений принята консервативная внутренняя проверка: минимум 700×320, только JPEG/PNG/GIF, реальные размеры и ненулевое число байтов. Это политика экспортёра, а не утверждение об универсальном актуальном минимуме Дзена. WebP отклоняется валидатором RSS и для обложки, и для изображений в теле. Импортёр файлов пока читает JPEG/PNG.

## Локальные команды

```powershell
npx tsx scripts/build-dzen-draft.ts --source=D:/revroute-os/40-marketing/articles/dzen-shorten-link-no-signup-2026-05.md --slug=shorten-link-no-signup --date=2026-10-04 --image-map=content/dzen/pilot-image-map.json
npx tsx scripts/build-dzen-preview.ts --draft=content/dzen/drafts/shorten-link-no-signup.json
npm run test:dzen-rss
npx tsc --noEmit
```

`--date` в локальном черновике — предполагаемая дата. Перед размещением на сайте поставить фактическую дату публикации; не обновлять её автоматически при редактировании.

Импортёр извлекает только раздел «Черновик статьи», исключая frontmatter и бриф. Он сохраняет текст, выделение, ссылки, простые списки и цитаты; связывает отдельный курсивный абзац после изображения с figcaption. Неизвестная разметка и сложные вложенные списки останавливают импорт. Карта изображений явно заменяет маленькие мобильные кропы оригинальными настольными снимками; изображения копируются без изменений. Узкие кропы 388 px не увеличиваются искусственно.

Файлы проверки: `tmp/dzen-rss/shorten-link-no-signup/preview.html` и `preview.xml`. Это локальная проверка структуры, не эмуляция редактора Дзена.

В локальном dev-сервере статья доступна также по адресу `/blog/preview/shorten-link-no-signup` в общей дизайн-системе сайта. Этот маршрут работает только в development, закрыт от индексации и не добавляет черновик в блог или RSS. В production он возвращает 404.

## Подключение канала — известный отказ от 2026-10-20

Для подтверждения сайта опубликован файл `public/zen_sM8sn1YLWt9qjw8zyWdiBOAZz3kJc8NuOjMA4Xq3CLLYScJTIadyt9zFwAp1l8KZ.html` с точным метатегом из Дзен-студии. Публичный файл отвечает HTTP 200; после нажатия «Проверить» и обновления Студии домен `revroute.ru` отмечен зелёной галочкой. Ответ штатного API настроек: `domain.status: "ok"`.

Подключение RSS находится в разделе «Свой сайт». При первой подаче 15 октября порог подписчиков был пройден, адрес сохранён и заявка принята на проверку. На снимке пользователя от 20 октября заявка уже отклонена; подтверждения повторной подачи нет. В настройках «Кросспостинг в Дзен» доступны другие источники — YouTube, Telegram и VK Видео Live.

1. Подготовить реальную стартовую подборку с учётом требований справки и согласовать материалы для синдикации.
2. Включать согласованные материалы в RSS с `mode: 'draft'`, сохраняя фактические даты и GUID. Первая проба должна подтвердить создание черновика.
3. После исправления содержимого повторно подать RSS через штатный интерфейс «Свой сайт» по согласованию с владельцем и сохранить фактический результат. Повторная подача пока не подтверждена; известный отказ не считать ожидающей заявкой.
4. Дождаться приёма ленты и найти пилот в черновиках. Не создавать его вручную вместо проверки автоматического импорта.
5. Проверить заголовок, порядок трёх изображений и подписи, подзаголовки, выделение, все ссылки, карточку и мобильный вид в самом Дзене.
6. После проверки вёрстки отдельно включать `mode: 'publish'` для согласованных материалов, которым нужна автоматическая публикация. Текущий пилот настроен на автоматическое создание черновика.

Условие о 10 стартовых материалах подтверждено официальной справкой. При первой подаче 15 октября в ленте была одна статья; этот исторический факт не описывает её текущий состав. Подготовка материалов на сайте, повторная подача, одобрение подключения и автоматический импорт проверяются отдельно.

## Источники и границы подтверждения

Официальная [справка по разметке RSS](https://dzen.ru/help/ru/website/rss-modify.html) прочитана через браузер 2026-10-15. Она подтверждает стартовые требования, режим `native-draft`, формат `format-article`, поддержку `figure/img/figcaption` и минимальную ширину изображения 700 px. Пилот использует JPEG. Справка перечисляет JPEG, PNG и GIF; валидатор RSS допускает только эти типы. WebP отклоняется.

[Единый RSS сайтов-партнёров](https://dzen.ru/help/ru/news/seamless/rss.html) относится к отдельной новостной схеме; её применимость к данному авторскому каналу не проверена.

Изучены первичные источники авторов интеграций, а не официальное подтверждение для нашего аккаунта:
- [Prozen — описание плагина](https://wordpress.org/plugins/prozen-integration-for-dzen/): совместимая лента, нормализация контента; приём в канале как итоговая проверка.
- [Dzen RSS Feed — спецификация реализации](https://github.com/Bormotoon/dzen-rss-feed/blob/main/docs/dzen-rss-spec.md): семантика RSS, whitelist, native-draft, format-article и требования к стартовой подборке.
- [Zhekich Feed Generator](https://wordpress.org/plugins/zhekich-feed-generator-for-dzen/): сообщает о переходе сайтов-партнёров на единую схему с 2026-07-13, описывает преобразование strong/em в b/i. Применимость новостного процесса к нашему авторскому каналу не подтверждена.

В реализации лимиты заголовка 140 символов, ленты 10 MiB и подборки 500 статей — консервативные ограничения проекта. Они не доказывают текущие лимиты аккаунта. Не обещаем импорт за 5–15 минут, модерацию за 72 часа, универсальный запрет UTM или конкретный метод DNS-подтверждения.

Последнее подтверждённое решение — отказ на снимке пользователя от 2026-10-20 при подтверждённом домене. Повторная подача и её решение неизвестны. Приём статьи и фактическое выполнение `native-draft` ещё не проверены.


## Как включить первую утверждённую статью

Первая статья уже согласована: `content/dzen/approved.ts` импортирует её JSON и включает запись в массив с `enabled: true`, `mode: 'draft'`, датой `2026-10-04`. Одна запись используется и страницей `/blog/<slug>`, и RSS. Для следующих согласованных материалов применяется тот же процесс:

```ts
import type { BlogPost } from '../blog'
import draft from './drafts/shorten-link-no-signup.json'

const post = draft.post as BlogPost
export const approvedDzenPosts: BlogPost[] = [{
  ...post,
  date: 'ФАКТИЧЕСКАЯ_ДАТА_ПУБЛИКАЦИИ',
  dzen: {
    ...post.dzen!,
    enabled: true,
    mode: 'draft',
    // При необходимости: publishedAt с точным временем и часовым поясом.
  },
}]
```

Заменить дату на валидную ISO-дату или задать publishedAt. Пример не вставляется автоматически. При смене slug сохранить существующий guid. Режим publish включается отдельно после проверки импорта. Повторно пересоздавать GUID ради повторного импорта нельзя.
