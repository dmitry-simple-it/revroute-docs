# Как экспортировать ссылки из RevRoute

В рабочем пространстве RevRoute вы можете экспортировать ссылки в CSV-файл. Это полезно, если вы хотите проанализировать данные локально или поделиться ими с внешними заинтересованными лицами.

Чтобы экспортировать ссылки, выполните следующие шаги:

<Steps>

<Step title="Откройте модальное окно экспорта ссылок">

    В рабочем пространстве RevRoute перейдите на страницу «Ссылки».

    Затем нажмите кнопку `⋮` справа от строки поиска, чтобы открыть меню дополнительных действий, и выберите **Экспорт ссылок** → **Экспорт в CSV**.

    ![Меню «⋮» на странице ссылок с пунктами «Импорт ссылок» и «Экспорт ссылок → Экспорт в CSV»](/images/ru/links/links-export-menu.jpg)

</Step>

<Step title="Выберите диапазон дат">

    Откроется модальное окно **Export links** (оно отображается по-английски). В поле **Date Range** выберите диапазон дат для ссылок, которые хотите экспортировать. По умолчанию выбран вариант **All Time** — RevRoute экспортирует все ссылки.

    ![Модальное окно Export links с выбором диапазона дат, столбцов и тумблером Apply current filters](/images/ru/links/export-links-modal.jpg)

</Step>

<Step title="Выберите столбцы для экспорта">

    По умолчанию RevRoute экспортирует следующие столбцы:
    - Short link
    - Destination URL
    - Clicks
    - Created at

    Набор столбцов можно изменить в разделе **Columns** — там также доступны **Leads**, **Conversions**, **Revenue**, **Link ID**, **Updated at**, **Tags** и **Archived**.

</Step>

<Step title="Примените текущие фильтры" optional>

    При необходимости включите тумблер **Apply current filters**, чтобы экспортировать только ссылки, соответствующие текущим фильтрам дашборда. Если тумблер выключен, будут экспортированы все ссылки.

</Step>

<Step title="Скачайте данные">

    После выбора диапазона дат и столбцов для экспорта нажмите **Export links**.

    Через несколько секунд CSV-файл будет загружен на ваш компьютер.

</Step>

</Steps>
