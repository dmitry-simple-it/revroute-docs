# Migrating from Short.io

Short.io is a popular URL shortener that lets you create short links, which can be used in your marketing campaigns, social media posts, and more.

## How to migrate from Short.io to RevRoute

If you're looking to migrate from Short.io to RevRoute, we've built a custom migration tool that will help you migrate your links in a few simple steps.

<Steps>

<Step title="Get your Short.io API key">

First, log into your Short.io account and navigate to the [Integrations & API](https://app.short.io/settings/integrations/api-key) page.

![API page in Short.io](https://s3.revroute.ru/dub-public/assets/help/short-api-page.png)

Click on "Create API Key", which will open a modal. Leave all the options at their defaults and click "Create".

![API key creation modal in Short.io](https://s3.revroute.ru/dub-public/assets/help/short-create-api-key.png)

Copy the created API key. You'll need it in the next step.

![Copy the created API key](https://s3.revroute.ru/dub-public/assets/help/short-copy-api-key.png)

</Step>

<Step title="Use the Short.io migration tool">

If you haven't already, [create a workspace on RevRoute](/help/managing-your-workspace/what-is-a-workspace#how-to-create-a-workspace).

<Info>
  **Protip**: Once you create your workspace, we generally recommend that you **_not
  [configure your domain](/help/managing-your-links/custom-domains/how-to-add-custom-domain)_** until
  you've migrated all your links. This will prevent any potential downtime for
  your links.
</Info>

Then, open the import dialog with this direct link: [app.revroute.ru/links?import=short](https://app.revroute.ru/links?import=short). For now, the **⋮** menu on the Links page only offers CSV import.

Paste the API key you copied in the previous step into the **Short.io API Key** field and click **Confirm API Key**.

![Import from Short.io dialog: Short.io API Key field and Confirm API Key button](/images/ru/links/migration/import-short-modal.jpg)

Behind the scenes, we'll fetch all your Short.io custom domains and the number of links for each. You'll be presented with a list of domains that we've found.

</Step>

<Step title="Select the domains you want to migrate">

Select the domains you want to migrate and click **Confirm import**. In just a few seconds, all selected links will be migrated to RevRoute.

Once all your links have been imported, we will send you an email to let you know that the migration is complete.

</Step>

<Step title="Configure your domain">

Once you receive the email, you can [configure your domain](/help/managing-your-links/custom-domains/how-to-add-custom-domain#step-2-configure-your-domain) by setting the right DNS records. This will ensure that your links are pointing to RevRoute and not Short.io. Once you've done this, you can start using your links!

</Step>

</Steps>

<Tip>
  If the import doesn't start, export your links from Short.io to a CSV file and
  [import them from CSV](/help/managing-your-links/migration-guides/how-to-import-csv).
</Tip>


## Which Short.io link attributes are migrated?

Here's a list of attributes that are migrated from Short.io to RevRoute:

1. Destination URL
2. Short link slug
3. Link creation date
4. iOS device targeting (if enabled)
5. Android device targeting (if enabled)
6. Archived status
7. Link title (as part of RevRoute's Custom Link Previews feature)
8. [Link tags](/help/managing-your-links/links/how-to-use-tags)

Here are the attributes that are not migrated:

1. Password protection
2. Link 404 URL
3. Link expiration date
4. Link redirect type (RevRoute uses 307 redirects for all links)
5. Link cloaking

If there are any attributes that you'd like to see migrated, please [send us an email](mailto:support@revroute.ru?subject=Short.io%20migration%20feedback) and let us know!
