## Серверный клиент RevRoute

Примеры ниже используют TypeScript-SDK из npm-пакета `dub`. В клиенте
обязательно указывается `serverURL` API RevRoute — без него SDK будет
обращаться не к нашему API.

```bash
npm install dub
```

```ts lib/revroute.ts
import { Dub } from "dub";

export const revroute = new Dub({
  token: process.env.REVROUTE_API_KEY, // секретный ключ rr_* из настроек воркспейса
  serverURL: "https://api.revroute.ru", // обязательно: адрес API RevRoute
});
```

<Warning>
  Секретный ключ (`rr_*`) держите в переменных окружения и не отдавайте в
  браузер. Ключ создаётся в разделе [API-ключей](https://app.revroute.ru/settings/tokens).
</Warning>

<Tip>
  SDK не обязателен: `/track/lead` и `/track/sale` — обычные HTTPS-эндпоинты,
  их можно вызвать из любого языка (см. [Track
  lead](/docs/api-reference/endpoint/track-lead)).
</Tip>
